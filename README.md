# Living Lyrics

Сцена для песен. Сверху — оригинал на языке и письме исполнения (арабский — шрифтом Мединского Мусхафа, персидский — насталиком, латиница — антиквой). Слова загораются в момент, когда их поют, строки появляются и уходят с анимациями, как в студийных lyric video. Под оригиналом — русский перевод, который успеваешь читать в темпе песни. Ниже — шарх: то, что перевод передать не смог. Во время инструментальных частей на сцене гравюра инструмента, лад и отсчёт до голоса.

Интерфейс — в духе iOS 26: стеклянный плеер, круглые кнопки, шторки, светлая и тёмная темы.

## Что внутри

| | |
|---|---|
| Библиотека | поиск по названию, поэту, языку; сгенерированные обложки |
| Сцена | пословная подсветка, 10 видов появления строк, живой фон из цветов песни, «дышащие» точки в паузах, титульная карточка |
| Слои | перевод, транскрипция кириллицей, историческое письмо, шарх — каждый включается отдельно |
| Ведение | «За музыкой» (без рук) или «Вручную» с паузой после каждой строки; свайп — соседняя строка |
| Плеер | перемотка, ±10 с, строки вперёд/назад, скорость 0,75–1,25× без изменения высоты, качество (высокое / экономия), выравнивание громкости, 10-полосный эквалайзер с пресетами, свой аудиофайл, экран блокировки и наушники |
| Редактор | `/song/<slug>/edit` — тап-синхронизация слов, точная подстройка, выгрузка `lyrics.json` |
| Методология | `/method` на сайте и `docs/methodology/` — регламент добавления песни для ИИ-агента |
| Доступ | пароль (cookie на 180 дней), можно добавить на экран «Домой» |

Клавиши на сцене: пробел — пауза, ← → — строки, Shift + ← → — ±10 с, T — перевод, K — шарх, F — убрать интерфейс.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # validate + typecheck + сборка в dist/
```

Ссылка на момент: `/song/karitas?t=95`.

## Добавить песню

Дайте агенту ссылку или файл и попросите добавить песню (навык `/add-song`). Он пройдёт 12 стадий из [docs/methodology](docs/methodology/README.md): опознание записи → аудио → структура и инструменты → текст как поётся → пословные тайм-коды → перевод → шарх → транскрипция → гравюры → хореография → проверка → публикация.

## Состояние трёх песен

`Karitas`, `I Have Come Alive`, `ONE` перенесены из прототипа: тексты, переводы и шарх переписаны, но **аудио нет, а тайм-коды черновые** (`timing.status = draft`) — нужен файл записи и выравнивание. Что именно не подтверждено, перечислено в `content/songs/<slug>/sources.md` и в `review` каждой песни.

## Устройство

- `content/songs/<slug>/` — данные песен; формат — [docs/data-format.md](docs/data-format.md)
- `src/scene/` — сцена и хореография; `src/player/` — воспроизведение; `src/pages/` — страницы
- `src/styles/tokens.css` — дизайн-токены; правила — [docs/design/design-system.md](docs/design/design-system.md)
- `scripts/pipeline/` — аудиоконвейер (Python); `scripts/tools/` — валидатор, заготовка песни, скриншоты; `scripts/art/` — генератор гравюр
- `middleware.ts` — пароль на Vercel (`SITE_PASSWORD`, `AUTH_SECRET`)
