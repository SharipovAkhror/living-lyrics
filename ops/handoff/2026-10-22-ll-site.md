Я проверяю и вливаю в `site/studio-pass` (fast-forward), только если `npm run gate` зелёный (запускаю сам) и кадры проходят мой просмотр. Ветка раунда после вливания удаляется. В `main` студию не вливать до «да» владельца через LL · Main.
- **Задание раунда:** `docs/tasks/_executor.md` (подставить `{{WT}}`, `{{BRANCH}}`) + текст раунда. Задания лежат в `work/review/round<N>-brief.md` основной папки (не в git). Запуск: `node C:/Users/User/.claude/plugins/cache/xai-grok-build/grok-build/0.2.1/scripts/grok-bridge.mjs run --background --write --model grok-4.7 --effort high --cwd <папка> --prompt-file <абсолютный путь>`.
- **Отчёт Grok:** `python ops/agents/last_report.py studio-pass`. Если там одна строка — нужное в предпоследнем сообщении `chat_history.jsonl` (скрипт берёт последнее сообщение без вызовов инструментов).
- **Оценка раунда — замороженная мерка:** `PYTHONIOENCODING=utf-8 python scripts/review/critique.py <N> ../living-lyrics-wt/studio-pass`.
