# Сдача дел между чатами

Когда чат разрастается (порог — 60 % контекста), он записывает сюда, что в движении, и передаёт работу новому чату с тем же именем; старый уходит в архив. Процедура — `docs/process/chat-rotation.md`. Файл: `<ГГГГ-ММ-ДД>-<чат>.md`, где чат — `ll-main`, `ll-site`, `ll-tech` или `ll-business`. Новый чат начинает с последнего файла своего имени. Владелец говорит только с **LL · Main**.
