# Ход работы

- `board.json` — доска: что идёт сейчас, что нужно от владельца, прогресс песен, путь «до новых песен», последние передачи работы. Обычный JSON, читает кто угодно. Обновляет тот, кто ведёт работу, после каждого шага (выдал задание, принял, решение владельца) и коммитит.
  Поля: `updated` (ISO, UTC), `headline`, `tasks[]` (`id`, `section`: `you` | `now` | `done` | `later`, `agent`, `status`, `title`, `what`, `now`, `next`, `worktree`), `songs[]` (группы строк: доказано / поставлено / всего), `roadmap` (шаги с весом и долей готовности), `feed[]` (не больше 8, новые сверху), `models`.
- `handoff/` — сдача дел чатов проекта (LL · Main, LL · Site, LL · Business).
- **Порядок в ветках:** на GitHub включено удаление ветки после вливания PR (`delete_branch_on_merge`, решение владельца 2026-10-20). Влитые без PR ветки убирает `.github/workflows/cleanup.yml` после каждого обновления `main`.
- Ветка `live` — живое состояние исполнителей, которое выкладывает Станция; `.github/workflows/station-watch.yml` раз в 15 минут проверяет, что она свежая, и открывает задачу `station-down`, если Станция молчит больше 30 минут.

Мод Dashboard, инструменты чатов и исполнителей, учёт расхода, машины владельца — в настройке владельца `agentic-os-live` (с 2026-10-23).
