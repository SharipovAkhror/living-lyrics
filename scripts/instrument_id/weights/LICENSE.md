# Лицензия весов

`probe.npz` — линейная голова поверх энкодера EfficientAT mn10_as. Сам энкодер в репозиторий не входит. Его код и веса — MIT, Copyright (c) 2022 Florian Schmid, https://github.com/fschmid56/EfficientAT.

Пока в обучении есть IRMAS, голову можно использовать только некоммерчески. Сайт Living Lyrics некоммерческий, поэтому файл лежит в репозитории. Так же решено для MMS.

| Набор | Лицензия | Карточка |
|---|---|---|
| TinySOL 6.0 | CC BY 4.0 | https://doi.org/10.5281/zenodo.3685367 |
| IRMAS, обучающая часть | CC BY-NC-SA 4.0 | https://doi.org/10.5281/zenodo.1290750 |

Аудио этих наборов в git нет. Клипы Wikimedia Commons, если они набрались, перечислены отдельно в `scripts/instrument_id/sources/<id>.csv`: у каждой строки свои адрес, лицензия и автор. Условие NC-SA относится к голове, в которой участвовал IRMAS, и не переносится на файлы Commons.

Голова без IRMAS основной не стала. Голос, фортепиано и гитара в обучении есть только из IRMAS: без этих записей якорь голоса нельзя назвать верным классом. TinySOL (CC BY 4.0) в смеси остаётся. Сравнение — по составу классов в `docs/analysis/instrument-id-eval.md`, не по второй голове.
