# Бизнес: вводная для разговора о монетизации

Это вводная для отдельного чата, где владелец обсуждает: что за бизнес может вырасти из Living Lyrics, можно ли на нём зарабатывать и как. Решения из этого разговора записываются сюда и в `docs/STATUS.md` → «Решения».

## Что такое проект сейчас

- Сайт-сцена для песен (https://living-lyrics.vercel.app, под паролем): оригинал крупно, перевод по стандарту научного перевода с досье источников на каждую строку, пояснения, живая сцена инструментов по видео концерта, официальные обложки, версия исполнения. Три песни Sami Yusuf; маршрут добавления новой песни описан и почти отрепетирован (`docs/methodology/`).
- Делает его команда агентов: Claude Code ведёт и принимает, Grok пишет код, Gemini смотрит видео. Всё состояние — в публичном репозитории GitHub.
- Затраты сейчас: подписки владельца (Claude, Grok, Google AI Pro), бесплатные тарифы GitHub и Vercel.

## Открытые вопросы для разговора

1. Модель денег: подписка, донаты, B2B (артистам и лейблам — «сцена» для их песен), образование (изучение языков и поэзии по песням), лицензирование своей технологии и переводов.
2. Права: что нужно, чтобы показывать тексты и записи публично и за деньги (договоры с артистом, лейблом, издателем; агрегаторы текстов); что можно делать уже сейчас без договоров (свои переводы и пояснения к свободным старым стихам).
3. Пароль на сайте: владелец думает его убрать. Без пароля записи и тексты становятся публичными — решать вместе с вопросом прав, не раньше.
4. Аудитория и первый шаг: кто первым заплатит или поможет (сам артист и его команда? слушатели суфийской музыки? изучающие языки?).
5. Затраты при росте: хостинг записей, лимиты агентов, юрист.
