# Инструменты: контракт для рисунков и анимации

Этот документ — «подложка» для того, кто будет перерисовывать инструменты (человек или агент любого провайдера). Рисунок может быть SVG, Lottie, Rive или 3D-моделью — сцене всё равно: она каждый кадр передаёт рисунку одни и те же числа, посчитанные из звука. Код контракта — `src/instruments/animation.ts`.

## Что рисунок получает каждый кадр (всё 0…1, функции времени)

| Вход | Смысл | Чем двигать |
|---|---|---|
| `draw` | появление | контуры прорисовываются |
| `hatch` | детали после контуров | штриховка, орнамент |
| `energy` | общая громкость | общее «дыхание» рисунка |
| `pulse` | атаки: удар по дафу, щипок струны | мембрана вздрагивает, струна щёлкает, кольца звенят |
| `sustain` | тянущийся звук: смычок, голос, долгая нота | струны вибрируют, смычок ходит |
| `breath` | воздух: най, дудук, голос | частицы воздуха у отверстий |
| `beat` | фаза доли (если найден ритм) | лёгкое покачивание |

Какая дорожка звука питает `pulse`/`sustain`/`breath`, зависит от семейства инструмента (`FAMILY_DRIVE`): ударные — от стема ударных, щипковые — от атак, смычковые и духовые — от «прочих» инструментов, голоса — от вокала.

## Откуда числа

`scripts/pipeline/features.py` (ветка `wip/sync-tools`, доделать) считает по записи и стемам (Demucs: ударные, бас, прочее, вокал) дорожки `loud`, `onset`, `bright`, `drums`, `bass`, `other`, `vocals` с частотой 20–50 в секунду и доли ритма → `public/audio/<slug>/features.json` (формат — `AudioFeatures`). Это небольшой файл, считается один раз в GitHub Actions; на телефоне ничего не анализируется.

## Требования к рисунку SVG (формат по умолчанию)

- Один файл на инструмент: `src/instruments/svg/<key>.svg`, `viewBox` по пропорциям инструмента (пропорция попадает в `src/instruments/art.json` командой `npm run art`).
- Цвет только `currentColor` (сцена красит под песню и тему); никаких фиксированных цветов и фонов.
- Классы частей:
  - `.d` — контуры, `pathLength="1"` (прорисовка через `stroke-dashoffset`);
  - `.h` — штриховка, `.fillin` — лёгкая заливка тонов;
  - `.str` — каждая струна отдельным путём (вибрация);
  - `.skin` — мембраны (пульс);
  - `.breath` — точки воздуха у отверстий духовых;
  - `.part-<имя>` — подвижные части (`.part-bow` смычок, `.part-jingles` кольца/тарелочки, `.part-hammer` молоточки сантура) с `data-pivot="x y"` — точкой вращения в координатах `viewBox`.
- `id` внутри файла уникальны в пределах файла (сцена добавляет суффикс, если на экране несколько копий).
- Органологическая точность важнее эффектности: пропорции, число струн, отверстий, колков — по справочнику.

## Другие форматы

- **Lottie**: маркеры `appear`, `idle`; входы — через сегменты или выражения с теми же именами (`pulse`, `sustain` …).
- **Rive**: state machine `Main` с числовыми входами `draw`, `energy`, `pulse`, `sustain`, `breath`, `beat` (0…1).
- **3D (glTF)**: модели собирает `npm run art3d` (Node, meshopt). Корень `instrument`, клип `idle` в файле есть, но плеер его не крутит: поза — функция `(drive, time)`, а не проигрывание клипа. Узлы и морфы:

  | Часть | Имя | Как двигается |
  |---|---|---|
  | струна | `part-string-<n>` (n с 1, от низкой), морф `vibrate` | вес `stringWeight`: амплитуда от `sustain` и `pulse`, косинус от секунд воспроизведения |
  | мембрана | `part-skin`, морф `hit` | вес `skinWeight` от `pulse` и секунд |
  | кольца | дети `part-jingles`; у узла extras `phase` (0…1 по кругу) и `axis` (направление смещения) | сдвиг `jingleShift` от `pulse`, без морфа |
  | весь инструмент | корень `instrument` | наклон `sway` от `beat` и `energy`; в 0 и 1 доли инструмент прямой |

  Секунды передаются вторым аргументом `update(drive, time)`. Одинаковые секунды после разных перемоток дают тот же кадр: состояние кадра не копится. Формулы — `src/instruments/render/pose.ts`.

  На сцене песни один холст WebGL и несколько объектов (`src/instruments/render/three.ts`, `mountStage`). В галерее у карточки свой холст, потому что карточки — отдельные элементы. three.js и декодер meshopt грузятся только когда модель нужна. Нет модели, нет WebGL, включено «Уменьшение движения» (в том числе системное) или устройство с Save-Data либо не больше 2 ГБ памяти — остаётся гравюра. Спокойная анимация объём не отключает.

  Стиль `instrumentStyle` в настройках сайта: `engraving` (контур оболочкой в шейдере и штриховка цветом песни; не OutlinePass) или `materials` (дерево, кожа, металл). Блок песни (`InstBlock`) секунды в сцену пока не передаёт: для этого нужен вызов `stageRef.sync(time, drives)`.

Любой формат подключается адаптером `InstrumentRenderer` (`mount`, `update(drive, time?)`, `dispose`). Сцена берёт объём, если для ключа есть файл в `public/instruments/3d/` и устройство его тянет; иначе остаётся SVG.

## Как проверить

`npm run art` (для SVG) → страница `/instruments` (галерея и проба раскладок) → песня с инструментальной частью: рисунок должен двигаться в такт (после того как появится `features.json`).
