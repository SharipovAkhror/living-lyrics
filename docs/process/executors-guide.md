# Исполнители: модели, оболочки, кому какая работа

LL · Ops, 2026-10-22. Сверху — коротко для владельца, ниже — подробно для агентов. Числа «наши» — из своих журналов (команда при каждом); «официальные» — с источником и датой. Где источник не первичный, так и написано.

## Коротко

1. **Antigravity «ленивый» прежде всего из-за настройки, а не из-за ума.** Из 146 его запусков за неделю 38 (26 %) упёрлись в «нет разрешения». Все 35 запусков, которые оборвались на ошибке, оборвались именно на этом: команда или файл вне рабочей папки. Пустой ответ, который LL · Site повторял до трёх раз, — это тот же отказ. Проба 2026-10-22: без флагов agy вернул «успех» с пустым ответом, а с `--add-dir <папка> --dangerously-skip-permissions` и Gemini Flash, и Claude Sonnet ответили верно.
2. **В agy нет Gemini Pro, только Flash** (`agy models`: `gemini-3.8-flash-high/medium/low`, Claude Sonnet 4.6, Claude Opus 4.6, GPT-OSS 120B). Flash — быстрая и дешёвая модель. Тонкую оценку дизайна или перевода ей поручать нельзя: для этого есть Claude Opus/Sonnet внутри agy или Claude Code.
3. **Правила Google ограничивают agy.** FAQ Antigravity: `agy -p` — для прямых скриптов и CI. «Обёртка agy внутри сторонних агентов» на потребительском плане не поддерживается, за доступ через сторонние инструменты возможна блокировка. Наши чаты Claude, которые сами вызывают `agy -p`, под это подпадают. Скрипты `watch.py` и `critique.py`, запущенные напрямую, — спорный случай. **Решение за владельцем** (вопрос — у LL · Main). До решения: agy только из готовых скриптов, никаких новых обёрток, проба A2 остановлена.
4. **Grok — главный исполнитель кода, но дорог на длинных сессиях:** 129 тыс. токенов контекста на каждый вызов. Ворота приёмки и потолок 30 млн / 2 ч (`executor-budget.md`) это закрывают.
5. **Claude Code — оркестрация и приёмка.** Расход Claude — контекст чата (336 тыс. на вызов). Ротация теперь на 30 %.

## 3. «Лень» agy: замер и лечение

Источник — `~/.gemini/antigravity-cli/conversations/*.db`, 146 разговоров с 16 по 22 октября. Скрипты разбора — в отчёте LL · Ops, таблица `steps`: `status = 7` — шаг упал, `error_details` — текст отказа.

| Что | Число |
|---|---|
| Разговоров | 146 (21 окт — 90) |
| С отказом в разрешении | 38 (26 %) |
| Оборвались на упавшем шаге | 35 (24 %); **все 35 — после отказа в разрешении** |
| Что отказано | `dir` / `Get-ChildItem` по `content\songs`, `python -c …` (проверки кадров и звука), `ffprobe`, чтение PNG в `living-lyrics-wt/*/work/…` (вне рабочей папки) |
| Модель | `gemini-3.8-flash-high` во всех, где модель видна |

Почему так. Задания писали «Never run commands», но Flash всё равно тянется к командам: проверить файл, померить звук. В режиме `-p` отказ кончает ход. Ответ пустой, статус «SUCCESS», и снаружи это выглядит как лень.

Проба A/B, 2026-10-22: одно задание — прочитать файл в worktree и посчитать строки командой. Правильно: 36 и 127.

| Вариант | Итог | Время | Токены |
|---|---|---|---|
| A: Flash high, без флагов | «SUCCESS», **пустой ответ** | 11 с | 10 тыс. |
| B: Flash high, `--add-dir <wt> --dangerously-skip-permissions` | верно, ровно в JSON | 27 с | 38 тыс. |
| C: Sonnet 4.6, те же флаги | верно, но JSON обёрнут текстом | 13 с | 25 тыс. |

Лечение (для запусков agy, которые владелец оставит):

1. `--add-dir` на каждую папку с входными файлами. Не копировать файлы в `work/review` основной папки.
2. Разрешения: `--dangerously-skip-permissions` вместе с `--sandbox` (команды в песочнице). Либо узкие правила в `~/.gemini/config/config.json` (`userSettings.globalPermissionGrants.allow`, например `command(regex:ffprobe .*)`).
3. `--json-schema` на каждый ответ; пустой `response` при статусе SUCCESS считать отказом, а не повторять вслепую.
4. Модель по работе: кадры и видео — Flash high; суждение (дизайн, перевод, приёмка) — Claude Opus 4.6 внутри agy или Claude Code. Flash на суждение не ставить.
5. В задании: «Готово, когда: …» и список проверок; «не задавай вопросов, делай».

### Шаблоны брифов

**Б1 — Grok, код** (`docs/tasks/_executor.md` + это):
```
Задача: <одна фраза>. Ветка <branch>, папка <wt>.
Читать только: <файлы>. Файлы > 30 КБ — по поиску и диапазону строк.
Готово, когда: <проверки командами: npm run validate, тест X, замер Y ≥ Z>.
Круг <n> из 3. В конце круга: коммит + строки «прошло / не прошло» по проверкам.
Стоп: 30 млн токенов или 2 ч — коммит, «где остановились», конец.
```

**Б2 — проверка кода:**
```
Проверь diff <base>..<branch> на ошибки. Не переписывай.
Готово, когда: список находок «файл:строка — что не так — как воспроизвести», или «находок нет».
```

**Б3 — agy, кадры и видео:**
```
agy -p "<задание>" --model gemini-3.8-flash-high --add-dir <папка с файлами> \
    --dangerously-skip-permissions --sandbox --output-format json \
    --json-schema <схема> --print-timeout 1200s
Задание: открой только <файлы>. Команды не нужны.
Готово, когда: каждое поле схемы заполнено по файлам; чего не видно — "unknown".
Не задавай вопросов. Пустой ответ = ошибка.
```
