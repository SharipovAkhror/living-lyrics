# Что такое хуки — с нуля

## Простыми словами

Хук — это правило «когда случится X, сделай Y», которое программа выполняет сама, без вопроса к человеку.

Пример из жизни: дверной звонок. Кто-то нажал кнопку (событие) — в доме звенит (действие). Вы не сидите и не смотрите в окно: звонок сам сообщает. Или будильник с правилом «в 7:00 — включить свет и музыку».

В Claude Code событий много: чат запустился, вы отправили сообщение, Claude собирается выполнить команду, Claude закончил ответ. К каждому событию можно «подвесить» действие — это и есть хук.

## Какие хуки есть на Станции

### 1. Наш мод Dashboard (живёт в репозитории, `ops/dashboard-mod/`)

| Когда | Что делает для вас |
|---|---|
| чат запустился | готовит сводку и проверяет, что всё на месте |
| вы отправили сообщение со словом «дашборд» или «штаб» | отвечает картинкой со сводкой вместо долгого ответа |
| команда `/dashboard` | то же — картинка со сводкой |
| Claude закончил ответ | обновляет состояние: кто работает, кто ждёт вас |
| над полем ввода | полоска: что идёт и что ждёт вас |
| запись в панель на claude.ai | пропускает без вопроса только записи самого мода в его панель, всё остальное — как обычно, с вашим разрешением |
| по таймеру (раз в 2 и 10 минут) | поднимает уснувшие чаты, собирает лимиты, отмечает «Станция жива» для сигнала на GitHub |

Отсюда же push на телефон: если чат ждёт вашего ответа дольше 2 минут или недельный лимит Claude дошёл до 95 %.

### 2. Orca (отдельная программа на Станции, не наша)

Orca при установке добавила свой хук в общие настройки Claude Code на этом компьютере: на каждое событие (старт, сообщение, каждая команда, конец ответа) она получает уведомление и ведёт свой учёт работы агентов. Для нашего проекта она ничего не делает; Claude она не мешает.

## Почему споткнулся Grok

Grok умеет читать настройки Claude Code — так задумано, чтобы людям, которые переходят с Claude, не настраивать всё заново. Поэтому Grok подхватил и хук Orca, который был написан для Claude.

У Grok этот хук не срабатывал и падал — на каждом шаге каждой сессии. За неделю — 67 тысяч сбоев. Работу он не останавливал (сбой хука Grok пропускает), но это лишний шум и лишнее время в каждом шаге.

Это как если бы вы переехали в другую квартиру, а соседский звонок по ошибке подключили к вашей двери: звенит на каждый шаг, а открыть некому.

## Как мы это исправили и что не даст повториться

- В настройках Grok (`~/.grok/config.toml`) выключено чтение хуков Claude: `[compat.claude] hooks = false`. Проверено тестовой сессией: остались только собственные хуки Grok, оба отработали без ошибок.
- У нашего проекта своих хуков в настройках Claude нет, так что Grok ничего нужного не потерял.
- LL · Ops раз в неделю смотрит расход и сбои исполнителей; новый поток ошибок такого рода он увидит в отчёте.
- Если на Станцию поставят новую программу, которая добавит свои хуки, — Grok их больше не возьмёт: чтение хуков Claude у него выключено целиком.
