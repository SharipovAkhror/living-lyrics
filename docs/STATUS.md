Ключ — переменная `AUDIO_KEY` в Vercel; сборка (`npm run build`) и `npm run dev` расшифровывают в `public/audio/` (в git не попадает). Локально ключ — в `.env.local` (не коммитится).
- Новая запись: `npm run audio:encrypt -- <slug>` после `process_audio.py`.

## Сеть и вычисления

- Облачная среда Claude Code не пускает на YouTube и HuggingFace. YouTube к тому же блокирует серверы (GitHub Actions, Vercel) проверкой «вы не бот», поэтому **записи даёт пользователь** (файлом).
- Тяжёлые шаги (Demucs, Whisper, выравнивание MMS) запускаются в **Vercel Sandbox** через MCP-инструменты Vercel: `scripts/pipeline/sandbox/setup.sh`, `analyze.sh`, `research.py`. Песочница клонирует публичный репозиторий и расшифровывает запись ключом из переменной окружения команды. Подробно — `docs/methodology/05-alignment.md`.
- GitHub Actions в этом репозитории работают (запуск пушем в ветку), но API Actions через прокси недоступен, а ключ туда передать нельзя без секретов — поэтому для аудио используется Vercel Sandbox.

## Решения

- Режим сцены — караоке: вся строка видна заранее полупрозрачной и заливается по мере пения, следующая строка видна заранее. Анимации — только те, что не прячут текст.
- Редактор тайм-кодов удалён: синхронизацию делает конвейер (Demucs → Whisper → MMS forced alignment), правки — в `lyrics.json`.
- Ручной режим упрощён до переключателя «Пауза после каждой строки».
