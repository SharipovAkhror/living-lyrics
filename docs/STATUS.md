## Как работать

- **Записи** приносит владелец файлом в чат (скачивает своим Telegram-ботом; облако с YouTube не качает). Записи в репозитории только зашифрованы: `content/audio-enc/<slug>/high.m4a.enc` (AES-256-GCM, ключ `AUDIO_KEY`). Ключ есть в Vercel (скрытый) и в секретах GitHub Actions; владельцу ключ отправлен файлом. Для локального `npm run dev` со звуком положите его в `.env.local` строкой `AUDIO_KEY=…`.
- **Тяжёлые шаги** (отделение голоса, выравнивание, признаки звука) — в GitHub Actions: проверено, что раннер расшифровывает записи (`.github/workflows/audio-check.yml`, `docs/analysis/actions-check.md`). Рабочий конвейер `pipeline.yml` — в ветке `wip/sync-tools` (T1). Статус запусков: `https://api.github.com/repos/SharipovAkhror/living-lyrics/actions/runs`.
- **Сеть облачной среды Claude Code** закрыта для большинства сайтов (WebSearch работает; GitHub и PyPI доступны). Страницы читать через Vercel Sandbox (`scripts/pipeline/sandbox/fetch_text.py`). На десктопе этих ограничений нет.
- `.claude/settings.json` разрешает рутинные команды без подтверждений.

## Что есть

- **Сцена — поток строк** (`src/scene/flow.ts`, `Scene.tsx`, `LineBlock.tsx`, `InstBlock.tsx`): текущая строка на матовой подложке в верхней трети, следующие видны заранее, повторы — отдельные строки с пометкой, смена голоса подписана. Тап по строке — играть с неё.
- **Пословная заливка выключена, пока тайминг не доказан** (`timing.status = draft` или флаг `timing-draft`): строка загорается целиком, отсчётов «через…» нет. Слова рисуются одним слоем; бледность — прозрачностью слова (нет двоения на соединениях букв).
- **Плеер**: дорожка с отмеченными проигрышами, ⏮ ▶︎ ⏭ (тап — строка, удержание — перемотка), подписанные «Перевод», «Пояснение», «Весь текст», «Настройки»; «О песне» — кто поёт и играет; одна шторка настроек.
- **Инструменты**: 25 гравюр (`scripts/art/`), несколько инструментов сразу (`src/instruments/layout.ts`, `src/scene/InstrumentStage.tsx`), галерея `/instruments`. Контракт для перерисовки и анимации от звука — `docs/instruments/animation-contract.md`, `src/instruments/animation.ts`.
- **Тексты**: правило «от оригинала» (`docs/methodology/04-text.md`, `canon.md`, валидатор сверяет строки). Найденные оригиналы для Karitas (официальные субтитры с временем!) и ONE — `docs/analysis/research/` (не перепроверены). Карта голоса и черновые транскрипты — `docs/analysis/<slug>.md`.
- **Тайминги всех трёх песен — черновые**, у Karitas разметка вообще от другой длины записи (490 с против 977 с) — это T2.
