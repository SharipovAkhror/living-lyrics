## Сеть и вычисления

- Облачная среда Claude Code не открывает YouTube, HuggingFace и большинство сайтов с текстами (WebFetch падает на DNS; WebSearch работает).
- **Vercel Sandbox** (через MCP Vercel): полный интернет, 4 vCPU / 8 ГБ, жёсткий предел 45 минут на сессию. Вывод инструментов MCP обрезается до ~2 000 знаков на элемент — длинное печатайте `scripts/pipeline/sandbox/dump.py`. Страницы читайте `scripts/pipeline/sandbox/fetch_text.py <url>`. Именованные песочницы с `persistent: true` сохраняют состояние между сессиями.
- **GitHub Actions** (в работе): `.github/workflows/pipeline.yml` — задание `jobs/<slug>.json` → разделение, выравнивание, проверка синхронизации → результат коммитом. Не зависит от среды агента. Нужен секрет репозитория `AUDIO_KEY` (добавляет владелец: Settings → Secrets and variables → Actions).
- Удалить ветку `ci/probe` на GitHub через прокси нельзя («remote end hung up») — её можно удалить в интерфейсе GitHub.

## Решения

- Сцена — поток строк как в Apple Music (`src/scene/flow.ts`): текущая строка на матовой подложке в верхней трети, следующие видны заранее, слова заливаются по мере пения; повторы — отдельные строки с пометкой; над строкой после долгой паузы — «через 0:08»; инструментальные части — гравюры на подложках, заранее объявлены строкой «Инструменты: …». Тап по строке — играть с неё.
- Плеер: дорожка, ⏮ ▶︎ ⏭ (тап — строка, удержание — перемотка), подписанные «Перевод», «Шарх», «Весь текст», «Настройки»; «О песне» — кто поёт и играет. Одна шторка настроек, эквалайзер — страницей внутри.
- Редактор тайм-кодов и ручной режим удалены. Время слов — только измеренное (выравнивание MMS по вокальной дорожке) и проверенное `qa_sync.py`; осталась настройка «Пауза после каждой строки».
- Тексты — от дословных оригиналов: `content/songs/<slug>/canon.md`, валидатор проверяет, что каждая строка в нём есть.
- Палитры — из кадров официальных видео (k-means), `docs/analysis/<slug>.md`.
