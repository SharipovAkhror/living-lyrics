# 9. Инструменты и гравюры

Во время инструментальных частей сцена показывает крупную гравюру инструмента, его название, исполнителя, лад и обратный отсчёт до голоса. Гравюры — векторные, в одном стиле: тонкий контур, гравировальная штриховка, геометрические розетки.

## Каталог

`src/instruments/list.ts` — список инструментов: ключ, название, название в оригинале, семейство, происхождение, одна фраза описания. В `lyrics.json` используются только ключи из каталога; валидатор это проверяет.

Есть гравюры: `oud`, `qanun`, `ney`, `daf`, `bendir`, `darbuka`, `santur`, `tanbur`, `baglama`, `erhu`, `violin`, `zurna`, `ensemble`.
Есть в каталоге, но без гравюры (покажется «ансамбль»): `tar`, `kamancheh`, `cello`, `duduk`, `piano`, `choir`.

## Как добавить инструмент

1. Добавьте запись в `src/instruments/list.ts`.
2. Создайте генератор `scripts/art/instruments/<key>.mjs` (образцы — `oud.mjs`, `qanun.mjs`; для длинногрифых лютен есть общий `scripts/art/lute.mjs`).
3. Соберите и посмотрите:
   ```bash
   npm run art -- <key>                    # пишет src/instruments/svg/<key>.svg и work/art/preview.html
   node scripts/art/shoot.mjs              # PNG в work/art/ — светлая и тёмная тема
   ```
4. Сравните с фотографиями настоящего инструмента: пропорции, число струн и колков, форма розеток, положение подставки.

## Стиль (обязательно)

| Параметр | Значение |
|---|---|
| Холст | `viewBox="0 0 400 400"`, инструмент вписан в медальон радиусом 186 |
| Цвет | только `currentColor` — сцена красит гравюру цветом песни |
| Заливки | нет, кроме `.fillin` (тон под штриховкой, прозрачность 12 %) |
| Контур | 1,2–1,7 для силуэта, 0,6–1,0 для деталей |
| Штриховка | 0,35–0,55, шаг 1,3–3; тень — с той стороны, куда не падает свет (свет сверху слева) |
| Ракурс | фронтальный или три четверти, лёгкий наклон (−40°…+40°) для динамики |
| Детали | те, что узнаются: розетки, число струн/хоров, лады, колки, кольца дафа, отверстия ная |
| Вес файла | до ~60 КБ (числа округлены до 0,1) |

## Классы для анимации

| Класс | Что делает на сцене |
|---|---|
| `.d` с `pathLength="1"` | контур «прорисовывается» при появлении (2,8 с) |
| `.h` | штриховка проявляется после контуров |
| `.fillin` | тон под штриховкой |
| `.str` | струны слегка дрожат, сильнее на громких местах |
| `.skin` | мембраны (даф, бендир, кожа эрху) пульсируют с громкостью |
| `.breath-dot` | дыхание у мундштука ная |

Все движения микро: амплитуда не больше 1 px, без медленных колебаний около 0,2 Гц (вызывают дискомфорт), отключаются при «Уменьшении движения».

## Критерий готовности

Ключ есть в каталоге, гравюра есть, в обеих темах читается с первого взгляда, файл не тяжелее ~60 КБ.
