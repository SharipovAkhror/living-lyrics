# 10. Хореография сцены

Сцена — как студийный lyric video: каждая строка появляется своим способом, слова загораются в момент пения, строка уходит своим способом. Обычно ничего настраивать не нужно: сцена сама выбирает анимацию по громкости и плотности текста и не повторяет одну и ту же дважды подряд.

## Как сцена выбирает

- **Спокойные места** (тихо, слов мало): `focus`, `ink`, `rise`, `whisper`, `spotlight`.
- **Насыщенные места** (громко или много слов в секунду): `assemble`, `drop`, `bloom`, `cascade`, `stack`, `rise`.
- Громкость берётся из `peaks.json`; без него — по числу слов в секунду.
- `stack` — только для коротких строк (до 4 слов), `cascade` — только для латиницы и кириллицы.

## Анимации

| `fx` | Появление | Уход | Подходит |
|---|---|---|---|
| `rise` | строка поднимается снизу, слова по очереди | вверх с размытием | универсально |
| `focus` | строка проявляется из размытия | расфокус | медленные строки, начало куплета |
| `ink` | каждое слово «пишется» в направлении чтения в момент пения; для арабского — справа налево, как каллиграфия | растворение | арабское и персидское письмо, мавваль |
| `assemble` | слова слетаются из разных мест и встают точно в момент пения | разлетаются | ритмичные места |
| `drop` | слова падают сверху с пружиной | падают вниз | ударные, припевы |
| `bloom` | слова распускаются из малого с мягким свечением | улетают на зрителя | кульминации, «ожил», «любовь» |
| `cascade` | буквы слова поднимаются по одной | осыпаются | короткие латинские слова |
| `spotlight` | строка целиком; поющееся слово крупнее и в цвете | гаснет | повторы, ключевые фразы |
| `stack` | слова одно под другим, въезжают с разных сторон | уезжают | короткие лозунги |
| `whisper` | медленное проявление | медленное угасание | тихие коды, шёпот хора |

## Когда вмешиваться

- **`fx`** у строки — если автоматический выбор не подходит смыслу: последнее «я ожил» — `bloom`, тихая кода — `whisper`, «Кто же я, о Я» — `spotlight`.
- **`^` (em)** — одно ключевое слово, которое должно загореться цветом песни.
- **`|` (br)** — перенос на цезуре, чтобы строка не рвалась посередине смысловой группы.

## Ограничения

- Арабское письмо никогда не делится на буквы и не разрежается трекингом: буквы связаны, разрыв их ломает. Поэтому `cascade` и `whisper` для арабских строк автоматически заменяются.
- Анимация — функция времени: перемотка назад показывает ровно тот же кадр. Не добавляйте эффекты, которые зависят от истории (накопление, случайность без зерна).
- Уважение к настройкам: «Спокойная» анимация оставляет мягкие появления и подсветку, «Без» — только подсветку слов. Системное «Уменьшение движения» включает «Без».
