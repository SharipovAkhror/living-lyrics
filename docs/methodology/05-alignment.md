# 5. Пословные тайм-коды

**Цель:** у каждого слова — время начала `s` и конца `e` в секундах от начала файла, с точностью до ~50 мс. От этого зависит всё «без рук»: подсветка слова, появление строк, анимации.

## Автоматически

```bash
python3 scripts/pipeline/align.py <slug>
```

Что делает:
1. Берёт вокальный стем `work/<slug>/stems/vocals.wav` (стадия 3) — без инструментов выравнивание в разы точнее.
2. Для каждой вокальной секции вырезает её отрезок (+0,5 с по краям).
3. Переводит слова в латиницу (uroman для арабского письма) и прогоняет многоязычный акустический выравниватель **MMS forced aligner** (torchaudio, 1100+ языков). Если доступен WhisperX и язык поддерживается — можно использовать его (`--engine whisperx`).
4. Записывает `s`/`e` в `lyrics.json`, ставит `song.json → timing = { status: "aligned", method: "mms-fa" }`.
5. Печатает отчёт: слова с низкой уверенностью, подозрительно короткие (< 80 мс) и длинные (> 4 с) слова — их нужно проверить вручную.

Особенности репертуара:
- **Мелизмы.** Одна гласная тянется на 3–6 секунд — это нормально для мавваля и мугама. Если выравниватель «сжал» слово, растяните его вручную.
- **Хор и солист одновременно.** Выравнивайте по главному голосу; в пояснении секции объясните, что тексты накладываются.
- **Повторы.** Каждое повторение — отдельная строка, иначе выравниватель «перепрыгнет».

## Вручную: редактор

Откройте `/song/<slug>/edit` на сайте (локально — `npm run dev`).

- Играет запись, слова идут списком.
- **Пробел** — поставить начало текущего слова в момент нажатия и перейти к следующему («тап-синхронизация»). Удобно на скорости 0,75×.
- **← / →** — сдвинуть выбранное слово на 50 мс, с Shift — на 10 мс.
- **Enter** — проиграть строку с её начала.
- Кнопка «Скачать lyrics.json» — сохраните файл в `content/songs/<slug>/`.

Проверяйте так: включите сцену, закройте глаза на секунду и откройте на любом слове — подсветка должна совпадать с голосом.

## Статусы

| `timing.status` | Когда ставить |
|---|---|
| `draft` | время оценено (скрипт `draft-timing` или перенесено из старых данных) |
| `aligned` | прошёл автоматический выравниватель, отчёт просмотрен |
| `verified` | человек прошёл песню целиком в редакторе и поправил всё, что съехало |

Снимайте флаг `timing-draft` со строк, когда время слов в них проверено.

## Критерий готовности

Валидатор не ругается на порядок слов; ни одно слово не начинается раньше конца предыдущего; ручная проверка на трёх случайных местах песни совпадает.
