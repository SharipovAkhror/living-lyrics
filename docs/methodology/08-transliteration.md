# 8. Транскрипция кириллицей

Слой «Как произносится» (`translit`) помогает подпевать тем, кто не читает арабское письмо. Он практический, а не научный: без диакритики, легко читается глазами в темпе песни. Включается в настройках «Вид».

Обязательна для строк арабским письмом (арабский, персидский, османский, урду). Для латиницы не нужна.

## Общие правила

- Передаём **как поётся в записи** (персидский — современное иранское произношение, если исполнитель поёт так; арабский — литературное).
- Слова — через пробел, как в оригинале; артикль и предлоги — через дефис: *ль-*, *би-ль-*, *ва-*, *фа-*.
- Ассимиляция артикля перед «солнечными» буквами: *аш-шамс*, *з-зунун*, *т-тараб*.
- Долгие гласные не отмечаем. Ударение не ставим.
- Первое слово строки и имена собственные — с прописной.
- Пунктуация — как в переводе.

## Арабский

| Буква | | Буква | | Буква | |
|---|---|---|---|---|---|
| ا | а | ز | з | ق | к (перед и: кы) |
| ب | б | س | с | ك | к |
| ت | т | ش | ш | ل | ль / л |
| ث | с | ص | с | م | м |
| ج | дж | ض | д | ن | н |
| ح | х | ط | т | ه | х |
| خ | х | ظ | з | و | в / у |
| د | д | ع | ‘ (U+2018) | ي | й / и |
| ذ | з | غ | г | ء | ’ (U+2019) между гласными, иначе не пишем |
| ر | р | ف | ф | ة | -а / -ат перед огласовкой |

Примеры: *Айни ли-гайри джамаликум ля танзуру*; *Хараджту фихи ба‘да ль-фана*; *Сукыту ка’са ль-хава кадиман*.

## Персидский

Как арабский, плюс:

| Буква / случай | |
|---|---|
| پ | п |
| چ | ч |
| ژ | ж |
| گ | г |
| изафет ـِ | -е (после гласной -йе): *доулат-е эшк*, *ханде-йе то* |
| و как союз | -о: *ман-о то* |
| ـه на конце | -е: *зенде*, *ханде* |
| ی на конце | -и |

Примеры: *Морде бодам, зенде шодам*; *Доулат-е эшк амад-о ман*.

## Тюркские в арабском письме

Если основная строка в латинице (как у Физули), транскрипция не нужна. Если поётся по-османски, а строки в арабском письме — передавайте по современной турецкой латинице, затем кириллицей по таблице: ö → ё, ü → ю, ı → ы, ş → ш, ç → ч, c → дж, ğ — не пишем.

## Проверка

Прочитайте транскрипцию вслух вместе с записью. Если вы её произносите, а певец — нет, исправляйте по записи.
