# 8. Транскрипция кириллицей

**Вход.** Строки, у которых `script` равен `Arab` или `Aran`. Латиница и кириллица этот слой не требуют.

**Команды.** Заполнить `translit` по таблицам ниже. Затем `npm run validate -- <slug>` и `npm run song-status -- <slug>`.

**Выход.** У каждой такой строки непустой `translit`: как поётся, кириллицей, без диакритики.

**Машинная проверка.** Валидатор предупреждает о пустом `translit` для `Arab` и `Aran`. `song-status` ставит «транскрипция» в «да», когда таких пустых строк нет. Если арабского письма в песне нет, строка таблицы сразу «да»: выдумывать транскрипцию латинице не нужно.

Слой «Как произносится» включается в настройках «Вид». Он практический: читатель подпевает в темпе песни. Научная транслитерация с макронами и точками на экран не идёт.

## Шаги

1. Возьмите `id`, которые напечатал `song-status` в стадии 8.
2. Прочитайте строку так, как она звучит в записи. Если записи ещё нет, читайте огласовки источника и поставьте флаг `text-unverified`, пока слух не подтвердит.
3. Запишите слова через пробел. Артикль и предлоги — через дефис: ль-, би-ль-, ва-, фа-.
4. Сверьте с таблицей этой страницы. Персидский, арабский и османский не смешивайте: у каждого своя колонка.
5. Прочитайте транскрипцию вслух вместе с записью, когда запись уже есть. Расхождение исправляйте по певцу.

## Общие правила

- Персидский — современное иранское произношение, если исполнитель поёт так. Арабский — как в записи; если сверки ещё нет, литературное чтение огласовок и пометка в `review`.
- Ассимиляция артикля перед солнечными буквами: аш-шамс, з-зунун, т-тараб.
- Долгие гласные не отмечаем. Ударение не ставим.
- Первое слово строки и имена собственные — с прописной.
- Пунктуация — как в переводе.

## Арабский

| Буква | | Буква | | Буква | |
|---|---|---|---|---|---|
| ا | а | ز | з | ق | к (перед и: кы) |
| ب | б | س | с | ك | к |
| ت | т | ش | ш | ل | ль / л |
| ث | с | ص | с | م | м |
| ج | дж | ض | д | ن | н |
| ح | х | ط | т | ه | х |
| خ | х | ظ | з | و | в / у |
| د | д | ع | ‘ (U+2018) | ي | й / и |
| ذ | з | غ | г | ء | ’ (U+2019) между гласными, иначе не пишем |
| ر | р | ف | ф | ة | -а / -ат перед огласовкой |

Примеры из наших строк: `one`, `shushtari-1-1` — «Хараджту фихи ба‘да ль-фана»; `karitas`, `mawwal-1-1` — «Йа сакийа ль-кауми мин шазаху».

## Персидский

Как арабский, плюс:

| Буква / случай | |
|---|---|
| پ | п |
| چ | ч |
| ژ | ж |
| گ | г |
| изафет ـِ | -е (после гласной -йе): доулат-е эшк |
| و как союз | -о: ман-о то |
| ـه на конце | -е: зенде |
| ی на конце | -и |

Письмо `Aran` (насталик) транскрибируется по этой же таблице, если строка персидская или урду. Образец персидской строки: `i-have-come-alive`, `rumi-1-1` — «Морде бодам, зенде шодам».

## Тюркские в арабском письме

Если основная строка уже в латинице, как Физули в `karitas` (`lang: az`, `script: Latn`), поле `translit` не заполняйте. Арабское письмо этого текста, если оно есть в источнике, живёт в `alt`, не вместо спетой строки.

Если поётся по-османски и строка набрана арабским письмом, передайте чтение современной турецкой латиницей, затем кириллицей: ö → ё, ü → ю, ı → ы, ş → ш, ç → ч, c → дж, ğ не пишем.

## Типичные ошибки

- Заполнить `translit` у латинской строки Физули или у Экхарта.
- Поставить диакритику «для точности».
- Скопировать чтение из словаря, когда певец произносит иначе. После появления записи правка идёт по записи.
- Искать в валидаторе предупреждение для иврита или деванагари. Такого предупреждения нет: кириллический слой обязателен для арабского письма. Другое письмо читатель видит своим шрифтом (стадия 10).
