# 1. Приём и опознание записи

**Вход:** ссылка (YouTube, Apple Music, Spotify, сайт исполнителя) или аудиофайл. Больше ничего.

**Цель:** точно знать, *какая именно* это запись, потому что у одной песни бывают студийная версия, живые версии с разных концертов, ремиксы, сокращённые клипы. Тайм-коды и текст подходят только к одной из них.

## Шаги

1. **Определите запись.**
   - По ссылке: название ролика или трека, канал (официальный ли), дата публикации, длительность, описание (там часто есть авторы текстов и музыканты).
   - По файлу: теги (`ffprobe -hide_banner file.m4a`), длительность, имя файла. Если тегов нет — распознайте фрагмент (Shazam, AcoustID) или найдите по длительности на официальных площадках.
   - Запишите: исполнитель, название, версия (студийная / live — где и когда), альбом, год, длительность до секунды.
2. **Найдите официальные описания.** Сайт исполнителя, страница релиза (Apple Music, Qobuz, Bandcamp), программа концерта, буклет. Ищите: авторов текстов (поэты, переводчики, переложения), языки, музыкантов-солистов, лады (макамы), место и дату записи.
3. **Выберите slug.** Латиница, нижний регистр, дефисы: `i-have-come-alive`. Для разных версий одной песни — суффикс: `one-live-amsterdam`, `one-studio`.
4. **Создайте заготовку:**
   ```bash
   npm run new-song -- <slug> "Название" "Исполнитель"
   ```
   Скрипт создаст `content/songs/<slug>/` с `song.json`, `lyrics.json` и `sources.md`.
5. **Заполните `song.json`:** `title`, `titleOriginal` (если у песни есть название на языке оригинала), `artist`, `featuring`, `release`, `performance`, `languages` (в порядке появления), `poets`, `duration`, `credits` — **только подтверждённые** имена. Всё остальное — в `review`.
6. **Подберите палитру.** `palette.accent` (светлая тема) и `palette.accentDark` (тёмная) — один оттенок, второй светлее. Требования к контрасту — в [дизайн-системе](../design/design-system.md#цвет-песни). `palette.field` — 3–4 цвета для живого фона: возьмите их из обложки релиза или из настроения записи (тёплые — для экстатичных песен, холодные — для созерцательных).
7. **Запишите в `sources.md`** всё, что нашли, со ссылками, и отдельно — что не подтверждено.

## Критерий готовности

Вы можете ответить на вопрос «это какая запись?» одной строкой, и на каждый факт в `song.json` есть ссылка в `sources.md`.
