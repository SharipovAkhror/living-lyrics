# 3. Структура: голос и инструменты

**Параллельно.** Да, вместе с текстом, переводом и видео, когда карточка есть. Границы без стемов или конвейера не выдумывать.

**Что сделать.** Команду печатает `song-status`. Если есть Python и ffmpeg: `separate.py`, затем `sections.py`. Черновик границ — `work/<slug>/sections.suggested.json`. Секунды переносят в `lyrics.json` и проверяют на слух. Если локальных инструментов нет, а на ветке есть `.github/workflows/pipeline.yml`, команда — `git add jobs/<slug>.json` со стадиями `separate` и `sections`. Если нет ни того, ни другого, строка «структура» становится «отложено», и следующая команда уходит в текст.

**Чем проверить.** `npm run song-status -- <slug>`: строка «структура» — «да», когда есть хотя бы одна вокальная строка.

**Готово, когда** секции покрывают запись без перекрытий, у инструментальной есть ключи из каталога, неопознанное — `ensemble` и флаг `attribution-unverified`. Голос без разобранных слов — секция `instrumental` с `voice` или `choir`, без строк-заглушек. Видео целиком и вступления инструментов — строка «видео» в стадии 9, не кадры ниже. `frames.py` — запасной разбор одной секции, если `vision.json` ещё нет.

**Цель:** разбить запись на секции двух видов — `vocal` (поют слова) и `instrumental` (вступления, проигрыши, соло, кода) — и для каждой инструментальной секции знать, *что за инструменты* звучат и кто играет.

## Отделить голос

```bash
python3 scripts/pipeline/separate.py <slug>        # Demucs htdemucs → vocals, drums, bass, other (четыре стема, без --two-stems)
python3 scripts/pipeline/sections.py <slug>        # предложит границы секций по энергии вокального стема
```

`sections.py` пишет `work/<slug>/sections.suggested.json`: отрезки, где голоса нет дольше 4 секунд, помечены как инструментальные. Это **черновик**: проверьте на слух.

Тонкие случаи:
- **Голос без разобранных слов** — вокализ, хор на одном гласном, слог, в котором нет стиха. Это секция `instrumental` с ключом `voice` (один голос) или `choir` (хор). Подпись — «Голос» или «Хор». Флаг `text-unverified`, пока слова не разобраны. Поле `note` — только если есть что сказать читателю (например, «хор подхватывает на одном гласном»); служебное «слова не разобраны» в `note` и в подпись не пишется: это говорит флаг. Строк в секции нет: ни «؟», ни «…», ни одной буквы вместо текста. Валидатор считает такую строку ошибкой.
- **Речитатив со словами** — `vocal`.
- **Мавваль со стихом** — `vocal`. Мавваль на одном слоге без слов — та же секция `voice`, не строка из слога.
- **Аплодисменты, разговор в начале** — не секция; сцена покажет титульную карточку.

## Определить инструменты

Инструментальные секции получают поле `instruments` — ключи из каталога (`src/instruments/list.ts`). Первым ставьте ведущий инструмент; сцена показывает все ключи сразу и сама выбирает раскладку ([стадия 9](09-instruments.md)).

Как узнать, что звучит:
1. **Видео.** Если есть видео концерта — извлеките кадры из середины каждой инструментальной секции:
   ```bash
   python3 scripts/pipeline/frames.py <slug>       # work/<slug>/frames/<section>-<sec>.jpg
   ```
   Посмотрите кадры: солиста обычно показывают крупно. Сравните форму инструмента с каталогом (описания и гравюры).
2. **Описание релиза и буклет:** там перечислены солисты и инструменты.
3. **Тембр.** Если видео нет: щипковые с «каплями» (уд, канун, тар), тянущиеся (най, дудук, эрху, кяманча, скрипка), ударные (даф — звон колец, рик — звон тарелочек, дарбука — сухие «тек», томбак — глубокий деревянный «дум», бендир — гудящие струны под мембраной), гнусавые громкие (зурна). При сомнении — `ensemble` и пометка `attribution-unverified`.
4. **Исполнители.** `performers` заполняйте **только** подтверждёнными именами (буклет, титры видео, официальный пост). Не подтверждено — имени нет на экране, оно уходит в `sources.md`.

Если инструмента нет в каталоге — добавьте его по [стадии 9](09-instruments.md).

## Поля секции

```json
{
  "id": "erhu-solo",
  "kind": "instrumental",
  "start": 78.4,
  "end": 106.2,
  "label": "Соло эрху",
  "instruments": ["erhu", "qanun"],
  "performers": ["Имя Фамилия (эрху)"],
  "mode": "Баяти",
  "note": "Двухструнная китайская скрипка ведёт мелодию, канун отвечает.",
  "comment": "Что важно услышать в этой части и почему."
}
```

- `label` — короткая подпись в обычном регистре; видна в шапке.
- `note` — одна-две спокойные фразы под гравюрой. Не реклама и не поэма.
- `mode` — макам или лад, **если известен** из источника.
- `layout` — обычно не нужен: раскладку гравюр сцена выбирает сама. Когда задавать вручную — [стадия 9](09-instruments.md).

## Критерий готовности

Секции покрывают всю запись без перекрытий, у каждой инструментальной есть ключи инструментов, у каждой вокальной — хотя бы одна строка (заполняется на стадии 4).
