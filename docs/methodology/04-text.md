# 4. Оригинальный текст

**Цель:** записать **то, что поётся** — слово в слово, с повторами, в правильной орфографии и письме — и разбить на строки, удобные для сцены.

## Где искать

| Язык / традиция | Первоисточники |
|---|---|
| Персидская классика (Руми, Хафиз, Саади, Аттар) | [Ganjoor](https://ganjoor.net) — номер газели, все бейты; печатные издания (Фурузанфар для «Дивана Шамса») |
| Османская и азербайджанская поэзия (Физули, Насими, Юнус Эмре) | Викитека (tr.wikisource.org), научные издания диванов (турецкие и азербайджанские); для Физули — латиница и арабское письмо |
| Арабская суфийская поэзия (Ибн аль-Фарид, аш-Шуштари, аль-Халладж, аль-Бусири) | изданные диваны, al-maktaba.org, aldiwan.net; хадисы — sunnah.com; Коран — quran.com (сура:аят) |
| Латынь (Хильдегарда, григорианика) | Cantus Index (cantus.uwaterloo.ca), Hildegard Society, Barbara Newman, «Symphonia» |
| Средневековый немецкий (Экхарт) | Deutsche Werke (Quint), Pfeiffer; современные переводы — для смысла |
| Современные тексты (английский, переложения, новые стихи) | только запись и официальные публикации исполнителя |

Сайты с «текстами песен» годятся лишь как подсказка: там часто ошибки и пропуски.

## Как реконструировать спетое

1. **Черновая транскрипция:**
   ```bash
   python3 scripts/pipeline/transcribe.py <slug>    # Whisper large-v3 по вокальному стему → work/<slug>/transcript.json
   ```
   Whisper узнаёт язык фрагментов и даёт слова с примерным временем. Для арабского и персидского ошибок много — это только карта.
2. **Найдите канонический текст** (таблица выше) и сопоставьте с транскрипцией: какие бейты поются, в каком порядке, что повторяется, где вставлены рефрены.
3. **Слушайте каждую строку.** Где транскрипция и канон расходятся — побеждает запись. Расхождение с каноном объясните в шархе (например, «в изданиях — …, здесь поётся …»).
4. Чего не удаётся разобрать — пометьте флагом `text-unverified` и вопросом в `review`.

## Орфография

- **Арабский.** Полные огласовки (харакаты), как в Мусхафе: читатель должен суметь пропеть. Шадда, танвин, сукун — по произношению в записи. Знаки пауз Корана в песнях не ставим.
- **Персидский.** Персидские буквы: `ی` (U+06CC), `ک` (U+06A9), а не арабские `ي`, `ك`. Полу-пробел ZWNJ (U+200C) в формах `می‌کند`, `بی‌حد`. Огласовки — умеренно, там, где без них неясно чтение (изафет `ـِ`, `ـُ`).
- **Османский / азербайджанский.** Основная строка — латиница так, как поётся (турецкое или азербайджанское произношение — по записи); арабское письмо — в `alt`.
- **Латынь, средневековый немецкий** — орфография источника (`Karitas`, `habundat`), без «осовременивания».
- **Кавычки и тире** в переводах — «ёлочки» и длинное тире; в оригиналах — как принято в языке.

## Разбивка на строки

Строка (`line`) — то, что сцена показывает за один раз.

- Одна строка = одно полустишие (мисра) или одна музыкальная фраза.
- Обычно 2–8 слов и не дольше 8–9 секунд пения. Длиннее — делите.
- Повтор — это новая строка (у неё своё время).
- Внутри строки можно задать перенос: `|` после слова (в данных — `"br": true`). Ставьте его на цезуре: `Öyle ser-mestem ki | idrâk etmezem dünyâ nedir`.
- Ключевое слово строки можно отметить `^` (в данных — `"em": true`): сцена выделит его цветом песни. Не больше одного на строку, и не в каждой строке.
- `voice` у строки — кто поёт, если отличается от голоса секции (дуэт, хор).

## Поля строки

```json
{
  "id": "rumi-1-1",
  "lang": "fa",
  "script": "Arab",
  "words": [
    { "w": "مُرْده", "s": 132.40, "e": 133.05 },
    { "w": "بُدَم", "s": 133.05, "e": 133.80, "br": true },
    { "w": "زنده", "s": 134.10, "e": 134.90, "em": true },
    { "w": "شُدَم", "s": 134.90, "e": 135.70 }
  ],
  "translit": "Морде бодам, зенде шодам",
  "tr": { "ru": "Мёртвым был — живым стал," },
  "sharh": "…"
}
```

Пунктуация прилипает к слову (`kimdir,`). Время слов на этой стадии можно оставить черновым: `npm run draft-timing -- <slug>` распределит его по слогам внутри секций.

## Критерий готовности

Каждую строку можно пропеть вместе с записью от начала до конца, ни одно слово не пропущено и не лишнее, письмо и орфография — по правилам выше.
