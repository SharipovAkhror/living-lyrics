# Дизайн-система

Ориентир — интерфейсы Apple iOS 26 (Liquid Glass) и Apple Music. Источник правды — `src/styles/tokens.css`.

## Принципы

1. **Стекло — только для функционального слоя:** шапка, плеер, шторки, круглые кнопки. Контент (текст песни, шарх, списки) — на обычных материалах. Так требует HIG: стекло в слое контента запутывает иерархию.
2. **Один акцент на экран.** Цвет песни (`--accent`) — у кнопки воспроизведения, ключевого слова строки, активных переключателей. Иконки и подписи монохромные.
3. **Текст песни главнее всего.** Интерфейс отступает: по тапу на сцену шапка и плеер прячутся.
4. **Без капса.** Подписи, заголовки групп, метки — обычным регистром.
5. **Движение по делу** и всегда отключаемое (настройка «Анимация» и системное «Уменьшение движения»).

## Типографика

Интерфейс — системный SF Pro (на устройствах Apple), иначе Inter. Размеры — Dynamic Type «Large»:

| Стиль | pt | Начертание |
|---|---|---|
| Large Title | 34 | Bold |
| Title 1 / 2 / 3 | 28 / 22 / 20 | Bold / Bold / Semibold |
| Headline | 17 | Semibold |
| Body | 17 | Regular |
| Callout / Subhead | 16 / 15 | Regular |
| Footnote | 13 | Regular |
| Caption 1 / 2 | 12 / 11 | Regular |

Тексты песен:

| Письмо | Шрифт | Межстрочный |
|---|---|---|
| Арабский, персидский (насх) | KFGQPC Uthmanic Script HAFS — шрифт Мединского Мусхафа | 1,62 |
| Персидский (по умолчанию) | Noto Nastaliq Urdu — насталик | 2,0 |
| Латиница, кириллица в оригинале | Cormorant Garamond 600 | 1,1 |
| Перевод, транскрипция | системный | 1,38 |

Размер оригинала подбирается автоматически: максимально крупно, чтобы строка заняла не больше половины высоты сцены (две трети без переводов).

Лицензия шрифта Мусхафа (KFGQPC) разрешает бесплатное использование и распространение без изменений — файл лежит в `public/fonts/` как есть, без конвертации.

## Цвет

Системные цвета iOS: `label`, `secondaryLabel` (60 %), `tertiaryLabel` (30 %), `fill`, `separator`, системный зелёный для переключателей. Светлая и тёмная темы; тема следует системе или выбирается вручную.

### Цвет песни

- `accent` — для светлой темы: контраст с белым не ниже 4,5 : 1.
- `accentDark` — для тёмной: тот же оттенок светлее, контраст с чёрным не ниже 4,5 : 1.
- `field` — 3–4 цвета живого фона. В светлой теме они смешиваются с белой бумагой, в тёмной — светятся на чёрном.

## Стекло

Рецепт (работает в Safari на iPhone):
- полупрозрачный тон (`--glass-tint`: 52 % белого / 42 % тёмного);
- `backdrop-filter: blur(22px) saturate(190%)`;
- блик по кромке: градиентная рамка 1 px, ярче сверху слева;
- внутренний свет сверху и мягкая внешняя тень;
- при нажатии кнопка слегка «вздувается» (scale 1,08) и светлеет — как в iOS 26.

«Уменьшение прозрачности» делает поверхности непрозрачными; «Повышенный контраст» усиливает кромки и приглушённый текст.

## Иконки

Нарисованы в духе SF Symbols (сами SF Symbols разрешено использовать только в приложениях для платформ Apple): сетка 24, линия 1,75, скруглённые концы; транспортные — залитые. Файл — `src/icons/Icon.tsx`.

## Движение

- Пружина `cubic-bezier(0.34, 1.36, 0.64, 1)` для кнопок и шторок, `ease-out` для появлений.
- Длительности: 120 / 220 / 360 / 520 мс.
- Шторки уходят свайпом вниз, по тапу на фон и клавишей Esc.
