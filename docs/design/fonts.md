# Шрифты

Токены в `src/styles/tokens.css` этой задачей не меняются. Пока владелец не выберет набор, сайт выглядит как раньше: персидский по умолчанию — Noto Nastaliq Urdu, арабский — файл Мединского Мусхафа, латиница и кириллица оригинала — Cormorant Garamond 600, перевод — системный шрифт.

Примерка накладывает набор поверх этих переменных. В адрес добавляется параметр:

- `?fonts=a` — набор A, «как сейчас»;
- `?fonts=b` — набор B, «книжный»;
- `?fonts=c` — набор C, «ясный»;
- `?fonts=off` — выключить и забыть выбор.

Пока примерка включена, внизу экрана (на странице песни — под шапкой) видна плашка «примерка шрифтов: набор B» и переключатель A / B / C / выкл. Выбор запоминается в этом браузере, пока его не выключат: переход по страницам сайта не сбрасывает набор. Другие параметры адреса, в том числе `?t=` (момент песни), сохраняются.

Файлы кандидатов запрашиваются у Google Fonts (CSS API) только для наборов B и C. Набор A и обычный сайт без параметра этих запросов не делают. В обычный бандл шрифты кандидатов не входят.

Откуда взяты кандидаты: исследование T3, `docs/research/technology.md`, раздел 5. Здесь — лицензии, покрытие и вес файлов, которые реально отдаёт примерка. Замеры 17 октября 2026: CSS API с агентом Chrome 131, размеры woff2 — длина ответа, глифы — таблица cmap (fontTools). Текст лицензии OFL сюда не копируется.

## Наборы

| | Персидский | Оригинал (латиница и кириллица) | Перевод | Лишняя загрузка |
|---|---|---|---|---|
| A, «как сейчас» | как в настройках: насталик Noto Nastaliq Urdu или, если выбран насх, мусхаф | Cormorant Garamond 600 | системный (на iPhone это SF Pro, на этой машине — Inter) | нет |
| B, «книжный» | Amiri, вес 400 | Source Serif 4, вес 600 | тот же Source Serif 4, вес 400 | да |
| C, «ясный» | Scheherazade New, вес 400 | EB Garamond, вес 600 | Literata, вес 400 | да |

Арабский во всех трёх наборах остаётся KFGQPC Uthmanic Script HAFS. Другую нарезку этого файла лицензия не разрешает, и примерка его не подменяет.

Набор A нужен как точка сравнения: это сегодняшняя пара, без новых файлов. Набор B — первая рекомендация исследования: книжный насх и одна антиква на оригинал и на перевод (перевод легче, чтобы строки не сливались). Набор C — если Amiri покажется слишком книжным, а перевод в наборе B сольётся с оригиналом: другой насх, другая антиква, у перевода свой читаемый шрифт с курсивом.

Межстрочный у персидского в примерке задан только для примерки, не в токенах: Amiri — 1,75, Scheherazade New — 1,9. Это стартовые значения, чтобы огласовкам было где стоять. Если на снимках знаки столкнутся, цифру поправят до выбора владельца.

## Набор A — как сейчас

Ничего не подменяется. Атрибут `data-font-preview="a"` только показывает плашку.

- Персидский по умолчанию: Noto Nastaliq Urdu, прямое начертание 400. В бандле один файл арабского подмножества, 159 368 байт (`@fontsource/noto-nastaliq-urdu/arabic-400.css`). Курсива у этого начертания нет. В каталоге Google Fonts у семейства языковое поле `ur_Arab`; персидские буквы, ZWNJ (U+200C) и огласовки в поставленном файле есть (cmap, эта проверка). Насталик остаётся обликом для знатока, как просит исследование.
- Если в настройках выбран насх, персидский идёт тем же мусхафом, что и арабский. Примерка это не трогает.
- Оригинал: Cormorant Garamond. В бандле только прямые 500 и 600, три подмножества: latin, latin-ext, cyrillic (`src/main.tsx`). Шесть файлов вместе 113 148 байт; из них вес 600 — 23 396 (latin) + 20 304 (latin-ext) + 13 016 (cyrillic). Курсив у семейства есть (отдельный вариативный файл, ось веса 300–700, лицензия OFL: [METADATA.pb](https://github.com/google/fonts/blob/main/ofl/cormorantgaramond/METADATA.pb), исходники [CatharsisFonts/Cormorant](https://github.com/CatharsisFonts/Cormorant)), но в бандл он не входит. Курсив оригинала на сцене сейчас и не запрашивается: класс `.f-serif` всегда прямой.
- В поставленных CSS-файлах Cormorant нет `unicode-range`. Глифы разложены по файлам, а браузер может взять один файл семейства и не подставить другой. Вместе три файла веса 600 содержат ə, ğ, ı, İ, ş, â, ä, ß, æ и кириллицу «а», «ё». По отдельности latin не содержит ə, ğ, ş, İ; latin-ext не содержит ı; cyrillic не содержит латинский список. На снимках набора A строку Физули нужно смотреть глазами: не подставился ли чужой глиф. Полный CSS API Google Fonts эти буквы содержит; бандл мы не расширяем.
- Перевод: системный стек (`--font-ui`). На iPhone владельца это SF Pro, у него курсив настоящий. На машине, где снимались образцы, SF Pro нет, и перевод рисует Inter. В бандле `@fontsource-variable/inter/index.css` семь лиц, все `font-style: normal`, с `unicode-range`. Курсив Inter в бандле не подключён: наклон у `em` и у транскрипции здесь синтетический. Русский перевод забирает cyrillic 18 748 байт и latin 48 256 байт. Буква ı входит в latin-диапазон (U+0131 явно), ə, ğ и ş — в latin-ext.

## Набор B — книжный

Запрос примерки: Amiri `ital,wght@0,400;1,400` и Source Serif 4 `ital,opsz,wght@0,8..60,200..900;1,8..60,200..900`. У Amiri на Google Fonts только веса 400 и 700. Если оставить сцене вес 600, браузер нарисует ложный полужирный. Поэтому персидская строка в примерке принудительно 400.

- Amiri. OFL-1.1, [репозиторий](https://github.com/aliftype/amiri) (в README лицензия и описание: классический насх, работа 2008–2022, версия 1 сочтена зрелой). Copyright 2010–2022 The Amiri Project Authors. Курсив настоящий, отдельный файл. Версия снятого woff2 — 1.002. В арабском прямом файле (108 560 байт) есть персидские پ چ ژ گ ک ی, ZWNJ и огласовки (фатха, шадда, сукун). Кириллицы нет. Глифа ə нет ни в arabic, ни в latin, ни в latin-ext — для азербайджанской ə Amiri не используется. Курсивный арабский файл (111 720 байт) сцена не запрашивает: персидская строка не наклонная. Прямой latin 19 544 байт подгрузится, только если в персидской строке встретится латиница.
- Source Serif 4. OFL, имя Source зарезервировано. Copyright 2014–2021 Adobe. Исходники [adobe-fonts/source-serif](https://github.com/adobe-fonts/source-serif), карточка [METADATA.pb](https://github.com/google/fonts/blob/main/ofl/sourceserif4/METADATA.pb). Отдельный курсивный вариативный файл. Оси: оптический размер 8–60, вес 200–900. Подмножества: cyrillic, cyrillic-ext, greek, latin, latin-ext, vietnamese. Арабского нет. Версия в таблице name снятого файла — 4.004. Объединение прямых latin + latin-ext + cyrillic содержит ə, Ə, ğ, ı, İ, ş, â, ä, ß, æ и кириллицу «а», «ё» (ê, î, û в эту проверку cmap не входили). По одному файлу буквы разложены подмножествами: это нарезка Google Fonts, не дыра. Глифа ZWNJ в этих трёх файлах нет — для арабского шрифт не берётся.
- Оригинал остаётся весом 600, как сейчас. Перевод — то же семейство, вес 400, оптический размер автоматический. Так проверяется совет исследования: один шрифт на оба текста. Если на образце перевод сольётся с оригиналом, это довод в пользу набора C.
- Типичная страница без курсива (персидская строка, русский перевод): Amiri arabic 108 560 + Source Serif latin 122 360 + latin-ext 100 872 + cyrillic 93 440 = 425 232 байта, около 415 КиБ. Курсивный cyrillic (90 356 байт) добавится, если включена транскрипция. Греческий и вьетнамский файлы страница песни не тянет.

## Набор C — ясный

Запрос примерки: Scheherazade New `wght@400`, EB Garamond `ital,wght@0,400..800;1,400..800`, Literata `ital,opsz,wght@0,7..72,200..900;1,7..72,200..900`.

- Scheherazade New. OFL-1.1, зарезервированы имена Scheherazade и SIL. Copyright 1994–2026 SIL Global. Страница [software.sil.org/scheherazade](https://software.sil.org/scheherazade/), исходники [silnrsi/font-scheherazade](https://github.com/silnrsi/font-scheherazade). Версия снятого woff2 — 4.500. Веса 400, 500, 600, 700, только прямое начертание: курсива нет. В арабском woff2 (79 368 байт) персидские буквы, ZWNJ и огласовки есть. В latin-ext (2 184 байта) нет глифов ə, ğ, ı, İ, ş. Для латиницы он не используется — только для персидской строки.
- EB Garamond. OFL, [METADATA.pb](https://github.com/google/fonts/blob/main/ofl/ebgaramond/METADATA.pb), исходники [octaviopardo/EBGaramond12](https://github.com/octaviopardo/EBGaramond12). Copyright 2017 The EB Garamond Project Authors. Курсив — отдельный вариативный файл. Ось веса 400–800, оптического размера нет. Подмножества: cyrillic, cyrillic-ext, greek, greek-ext, latin, latin-ext, vietnamese. Вес 600 внутри оси. Объединение прямых latin + latin-ext + cyrillic закрывает тот же проверенный список букв, что и Source Serif 4. Версия снятого woff2 — 1.003.
- Literata стоит на переводе, не на оригинале. Исследование просило сравнить Source Serif 4 с нынешним Cormorant и ещё с одной антиквой — EB Garamond или Literata. EB Garamond ближе к «серьёзной антикве» и поэтому на оригинале. Literata — читаемый текстовый шрифт с настоящим курсивом, чтобы перевод не был вторым гарамондом. OFL, [METADATA.pb](https://github.com/google/fonts/blob/main/ofl/literata/METADATA.pb), исходники [googlefonts/literata](https://github.com/googlefonts/literata). Copyright 2017 The Literata Project Authors. Оси: оптический размер 7–72, вес 200–900. Курсив отдельным файлом. Те же подмножества, что у EB Garamond. Объединение прямых файлов закрывает тот же проверенный список букв. Версия снятого woff2 — 3.103.
- Типичная страница без курсива: Scheherazade arabic 79 368 + EB Garamond latin 44 336 + latin-ext 113 928 + Literata cyrillic 61 688 + latin 110 080 (знаки препинания перевода тянут latin) = 409 400 байт, около 400 КиБ. latin-ext Literata (89 668 байт) — только если переводу нужна буква из этого диапазона.

## Курсив на сцене

В трёх `lyrics.json` у строк, с которых сняты образцы, нет разметки `*курсив*` и `**полужирный**` в переводе. Наклонный текст в сцене сегодня один: транскрипция (`.fb-translit`), и она скрыта, пока в настройках не включена «транскрипция». Оригинал латиницей и персидская строка курсивом не набираются.

Поэтому обычный кадр показывает прямое начертание. Отдельные снимки с включённой транскрипцией показывают курсив перевода: у набора A на этой машине он синтетический (Inter), на iPhone владельца — настоящий SF Pro; у наборов B и C курсив настоящий, `font-synthesis: none`, чтобы при отсутствии файла браузер не подделывал наклон.

Курсив Amiri и курсив антиквы для оригинала в запрос наборов B и C входят, но сцена их на строку оригинала не вешает. Это честно записано здесь, а не спрятано в образце.

## Арабский

KFGQPC Uthmanic Script HAFS, файл `public/fonts/KFGQPC-Uthmanic-Script-HAFS.otf`, 246 428 байт, версия 0.09. name ID 1 и 4: «KFGQPC Uthmanic Script HAFS». Лицензия не OFL. В name ID 13 — бесплатно Use, Copy, Distribute и запрет Sold, Modified, Altered. В name ID 0 — нельзя воспроизводить и менять без письменного разрешения комплекса короля Фахда, copyright 2010. Эти две записи противоречат друг другу. Юрист это не разбирал. Практика проекта, уже записанная в дизайн-системе: файл лежит как есть, без сабсета и без конвертации. Примерка его не перепаковывает.

В cmap файла есть персидские буквы, ZWNJ, фатха, шадда, сукун. Для арабской строки этого достаточно, и все три набора оставляют её на этом файле.

## Запасной насх, которого нет в переключателе

Noto Naskh Arabic. OFL, [notofonts/arabic](https://github.com/notofonts/arabic). Вариативный файл, вес 400–700, курсива нет. Версия 2.021. В карточке Google Fonts среди языков есть `fa_Arab`. Арабский woff2 запроса `wght@400..700` — 94 032 байта; в нём персидские буквы, ZWNJ и огласовки есть, кириллицы нет, глифа ə нет. Исследование ставит его запасным, «менее издание», чем Amiri, а рядом с Amiri называет Scheherazade New. В трёх кнопках место одно, его заняла Scheherazade. Вопрос владельцу: заменить ли в наборе C Scheherazade на Noto Naskh.

## Чего нет в тексте этих трёх песен

Покрытие ниже всё равно нужно: проект не кончается этими песнями.

- Буква ə есть в антологии азербайджанского текста в `content/songs/karitas/canon.md` (строки 66–75; оговорка на строке 63), но не в спетом `lyrics.json`. Строка Физули в сцене — османско-турецкая орфография подписей: ğ, ş, ı, циркумфлексы. Это `content/songs/karitas/lyrics.json`, секция `fuzuli-3`, строка `fuzuli-3-1`.
- Экхарт в сцене — немецкий без букв вне ASCII (`content/songs/one/lyrics.json`, секция `eckhart-1`). В `content/songs/one/canon.md` раздел 1 — как поётся, без циркумфлексов; циркумфлексы издания — в разделе 2, на сцену они не выводятся.
- Кириллического оригинала в этих трёх песнях нет. Кириллица перевода есть. Шрифт оригинала всё равно должен уметь кириллицу.
- ZWNJ в спетой персидской строке есть у `rumi-3-1` (`content/songs/i-have-come-alive/lyrics.json`, слово около строки 1965). Первый бейт Руми, с которого сняты основные кадры, этого знака не содержит. Отдельные кадры секции «Руми: всё благодарит» сняты из-за него.
