# Исправленные дефекты студийного прохода

Каждый дефект, который однажды исправлен, получает строку и одну проверку. Имя проверки содержит номер (`D9 drawn-text-no-overlap`). Считается нарисованное: рамки, непрозрачность, контраст, разница пикселей. Число узлов и длина расписания анимации проверкой не являются. Раунд вливается в `site/studio-pass`, только если `npm run gate` зелёный. Номер не переиспользуется.

Проверки D1–D19 и D21–D27 выполняет `scripts/perf/defects.mjs`, D28–D33 (движение) — `scripts/perf/motion.mjs`. D20 — строка `speed budget ok` в `npx vite build`. Геометрия 12 листов — `scripts/perf/geometry.mjs` против `tests/baselines/geometry.json` (±4 px по месту, ±4 % по размеру). Сдвиг базы проходит только коммитом, который её обновляет; отчёт раунда перечисляет каждый сдвиг и причину.

В WebKit на Windows отрисовка программная: любой кадр приходит через 45 мс (пустая страница) — 150 мс (библиотека, плотность 2), там судится время от первого кадра; оба числа печатаются. | D30 | 21 | Остановки и вспышки во время движения | `D30 continuity`: перелёт, смена строки при игре, отпускание перемотки. Шаг кадра — средняя разница каналов с предыдущим. Вспышка: шаги в кадр и из кадра оба больше 3 × медианы последовательности, а соседи друг с другом сходятся (разница через кадр меньше половины). N = 3: на записях раунда 20 самая большая такая пара — 1,64 медианы (палец нарочно качнулся на 1 px). Остановка: дыра внутри движения (шаг в кадр перед ней и из неё больше 1) дольше max(120 мс, 3 × медианного промежутка) плюс один кадр трансляции, 24–48 мс. Порог max(120, 3 × промежутка) не поднят: под параллельной геометрией дыра перелёта Chromium садилась на 1–13 мс выше него и на повторе проходила, а блок 400 мс и посаженная задержка около 560–610 мс этот запас перекрывают. Если за дырой кадр пришёл через < 8 мс, кадр был нарисован вовремя и задержан трансляцией: из дыры вычитается один промежуток. Доказано `npm run gate:prove`: `?ll-mutate=c` замирает перелёт и даёт одну белую вспышку; оба движка — FAIL, в строке есть и `spikes`, и `stalls`. Вписанный блок 400 мс (`--inject stall`) строка по-прежнему ловит |
