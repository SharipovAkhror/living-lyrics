# Noor — обходы маршрута

Ролик один: https://www.youtube.com/watch?v=rDn0kRoK0Mo , канал Sami Yusuf, 6:34. Звук — одна попытка дорожки 140. Арабская и турецкая дорожки скачаны той же одной попыткой субтитров. Английской дорожки в ответе не было, повторно не запрашивалась.

## Распознавание

`python scripts/pipeline/transcribe.py noor` падает сразу: `device=auto` выбирает CUDA, а библиотеки `cublas64_12.dll` нет. Скрипт репозитория не менялся. Свидетель порядка снят тем же вызовом, с `device=cpu` и `compute_type=int8`, в `work/noor/transcript.json`. Получилось четыре отрезка на всю запись: фильтр голоса почти всё отбросил. Буквы из него в `lyrics.json` не копируются. В `docs/analysis/noor/transcript.json` копия не кладётся, пока проверка порядка на таком обрывке даёт ложные ошибки.

## Кадры

`agy` не вызывался. Кадры `work/noor/check-frames/` прочитаны здесь. Текста песни на экране нет, ролик концертный. Отсюда `docs/analysis/noor/vision.json`. Инструменты из описания ролика (tar, santur, kamancheh, sitar, tablas) в кадр не переносились: в просмотренных кадрах видна только табла, один план, без имени.

## Обратный перевод

По заданию этой песни проверку перевода и пояснений делает Codex (`gpt-6.1-sol`, high), один раз, не Gemini. Заголовок «Обратный перевод» в досье появляется после этого прохода.
