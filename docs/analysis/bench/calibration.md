# Калибровка отбора строки

Порог выбран по всем строкам с репликой, которые собрал `--collect`, сразу по трём песням. Принята строка, у которой оценка не ниже порога и есть |начало − реплика|. Цель — максимум принятых с |Δ| ≤ 0,3 с. Доля принятых с |Δ| > 0,7 с не выше 2 %: ложных × 50 ≤ принятых. 1 из 50 проходит, 1 из 49 нет. Колонка «поставлено» считает строки, которые прошли бы и порог, и структуру, и |Δ| ≤ 0,3 с. Для строки с репликой конвейер этот порог больше не применяет: поставленной её делает структура и |Δ| ≤ 0,3 с, а оценка остаётся в отчёте. Для строки без реплики порог остаётся воротами. Разрыв с другой меткой записан в строке и в отбор не входит.

Выбрана оценка `word_mean`, порог 0,290. Ограничение уложился в 2 %.

Строк в сборе: 249. Из них с репликой и началом: 249.

Оценки: `letter` — средняя вероятность букв (уже нормирована на длину); `word_mean` — среднее по словам; `word_min` — самое слабое слово. Отдельной нормировки сверх средней по буквам нет: это та же величина.

Структурные проверки, независимо от оценки: слова по порядку; нет съеденного слова (пропуск или два начала ближе 0,02 с); нет двух подряд промежутков между началами короче 0,06 с; конец последней буквы не позже начала следующей реплики больше чем на 0,05 с. Последнее слово на короткость не проверяется: звезда держит мелизм, всплеск буквы — один кадр.
