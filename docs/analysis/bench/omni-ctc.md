# Omnilingual CTC 300M, латынь и азербайджанский

Карточка ровно `omniASR_CTC_300M`. Не LLM-ASR, не 1B, не 3B, не 7B, не v2. Часы — Витерби проекта по логитам известной строки, не распознавание. Окно 40 с и длиннее пропускается и не режется. Арабский, английский, персидский, турецкий и немецкий этим проходом не мерились. Время строк меняется только если опубликованных строк стало больше и база 158 удержана.

Лицензия: `Omnilingual ASR code and models are released under the [Apache 2.0](./LICENSE).`. Бюджет 4200 с. прибавки опубликованных строк нет, файлы возвращены
