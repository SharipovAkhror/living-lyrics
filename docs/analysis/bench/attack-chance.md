# Случайный проход атаки

Замер на вокальном стеме, только по поставленным строкам, после выравнивания всех песен задания и до проверки. Плотность — медиана промежутка между атаками при силе пика 0,5. Случайный проход — доля начал, которые после сдвига всё ещё оказываются не дальше допуска от какой-нибудь атаки (для правила с обязательным вторым выравнивателем — ещё и не дальше 0,10 с от его начала). Перемешивание — каждое слово получает начало следующего слова той же строки. В зачёт идёт худшая из этих долей. Предел 15 %. Доля доказанных — слова поставленных строк, которые проходят полное доказательство, включая путь без атаки.

У допуска 0,10 с случайный проход 0,752. Выбрано допуск 0,10 с, хор 0,20 с, сила пика 0,7, согласие второго выравнивателя: случайный проход 0,048, доля доказанных слов 0,525.

Правило: `tol-0.10-h0.7-second`. Случайный проход 0,048. Доказано слов 289 из 550.
