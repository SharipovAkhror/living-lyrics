# Досье перевода: for-true-lovers

Сверка 2026-10-31. Повтор одной формулировки описан один раз, каждый id назван. Подстрочник — рабочий разбор, на экран не идёт. Страницы Redhouse и Lane для этих слов в этом проходе не открывались: где нет другой открытой опоры, стоит «требует проверки». Буквы — из `content/songs/for-true-lovers/canon.md`.
