# Досье перевода: Healing

Английские буквы — блок LYRICS в описании официального видео. Словарь и страница с разбором строки не открывались. Чего нет в этом блоке, в перевод не добавлено. Обратный перевод этим проходом не делался: в review песни стоит «обратный перевод: ждёт Gemini».

Повтор припева назван отдельной строкой. Общая формулировка не склеивает разные печатные буквы (`bring` / `brings`, `let's` / `lets`).

## e1

Строки: e1

Оригинал: It's so hard to explain

Подстрочник: it is so hard — «это так трудно»; to explain — «объяснить».

Источник: описание https://www.youtube.com/watch?v=Tug63dI4MEY, блок LYRICS. Словарь не открыт — требует проверки.

Принято: Так трудно это объяснить

Не поместилось: «so» сжато в «так».
