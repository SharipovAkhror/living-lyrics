Видео концерта просмотрено по кадрам. `lyric_frames.py` снял 236 кадров в `work/ya-rasul-allah/lyric-frames/` (в git не входят). Буквы кадров через `agy` не читались: это запуск Claude · Lead, не этот проход. `captions.json` поэтому не записан. `cues.json` не писался: опоры титров нет. ## Скрипт транскрипции

`python scripts/pipeline/transcribe.py ya-rasul-allah` на этой машине падает: `device=auto` ищет CUDA и не находит `cublas64_12.dll`. Файл скрипта не менялся. Черновик порядка снят отдельным запуском той же модели на CPU, вне репозитория. Буквы и секунды этого черновика в `lyrics.json` как доказательство не переносились. Где опора одна и ей был дан текст страницы, у строки стоит `text-unverified`, а id назван в `review`.
