Оба разбиения оптимистичны: исполнитель не удержан. Дополнительные клипы: запись целиком в одной доле. В тест уходит самая крупная запись, после которой в обучении остаётся не меньше 15; при равенстве берётся Commons. Свой класс входит в голову, только если на этой чужой записи точность не ниже 0,8 и полнота не ниже 0,3 при опоре не меньше 8 окон. Веса некоммерческие: да. IRMAS на Zenodo помечен CC BY-NC-SA 4.0. Веса обучены и на этих записях.
Записи датасетов в git не входят. В репозитории только линейная голова `scripts/instrument_id/weights/probe.npz`.
Голова без IRMAS основной не стала: голос, фортепиано и гитара взяты только из IRMAS. Без них якорь голоса нельзя закрыть верным классом. Условие NC-SA записано в `scripts/instrument_id/weights/LICENSE.md`.

## Leave-one-song-out

Нужны сразу эмбеддинги публичного набора (work/instrument_id/embeddings.npz) и расшифрованная запись хотя бы одной песни с подтверждёнными двумя источниками отрезками. Локально есть эмбеддинги и нет ключа записи. На раннере есть запись и нет эмбеддингов. Число не подставлено.

## Чего модель по звуку не знает

Класс без 15 клипов из 3 записей в голову не входит. Свой класс, который на чужой записи не держит точность 0,8 и полноту 0,3 при опоре от 8 окон, тоже не входит. Классы TinySOL и IRMAS вторым условием не режутся: их доля не откладывает исполнителя. Чужой звук закрытая голова может уверенно назвать ближайшим знакомым классом: порог softmax это не лечит. Такой ответ не становится решением, если его не подтвердил второй источник. Кадр концерта — второй источник, и только если владелец положил файл видео.
