## Чего модель по звуку не знает

Уд, най, даф, канун, танбур, кяманча и остальные классы без примеров в голове не появляются. Путаница скрипки с кяманчой возможна и будет лишней относительно титров, а не доказательством класса. Кадр концерта — второй источник, и только если владелец положил файл видео.
