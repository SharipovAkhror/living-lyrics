## Leave-one-song-out

Нужны сразу эмбеддинги публичного набора (work/instrument_id/embeddings.npz) и расшифрованная запись хотя бы одной песни с подтверждёнными двумя источниками отрезками. Локально есть эмбеддинги и нет ключа записи. На раннере есть запись и нет эмбеддингов. Число не подставлено.

## Чего модель по звуку не знает

Класс без 15 клипов из 3 записей в голову не входит. Чужой звук закрытая голова может уверенно назвать ближайшим знакомым классом: порог softmax это не лечит. Такой ответ не становится решением, если его не подтвердил второй источник. Кадр концерта — второй источник, и только если владелец положил файл видео.
