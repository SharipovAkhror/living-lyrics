# The Creator — решения маршрута

Песня добавлялась одним агентом, без чата и без agy.

## Звук

Официальный ролик: https://www.youtube.com/watch?v=2WMvZdhDXwY , канал дистрибуции «Sami Yusuf - Topic», Andante Records, Spiritique Collection, 2015-03-01, 413,45 с. Одна попытка yt-dlp, дорожка 140. Ролик 2004 года (The Careator) не скачивался.

`process_audio.py` записал открытый файл и пики. Шифр — перед коммитом.

## Субтитры и кадры

Одна попытка официальных субтитров: для запрошенных языков их нет. В review стоит фраза «официальные субтитры: пусто». Повторно yt-dlp не запускался.

Видео формата 18 скачано одной попыткой. Тринадцать кадров по ролику побайтно совпали: статичная обложка, букв песни нет. `lyric_frames.py` оставил один кадр. `captions.json` записан по этому просмотру: `video_type` = static, массив титров пуст. agy не вызывался, `vision.json` не сочинялся.

## Голос и границы

`separate.py` отработал. `sections.py` дал черновик: инструменты 0–2,65 с, голос 2,65–404,35 с, инструменты 404,35–413,45 с.

`transcribe.py` из репозитория упал: faster-whisper на этой машине не нашёл cublas64_12.dll. Скрипт репозитория не менялся. Та же модель large-v3 была запущена отдельно на CPU и записала `work/the-creator/transcript.json`. Этот файл в git не входит. Его буквы в строки не копировались.

## Почему нет cues.json и нет задания

Ни субтитров, ни текста на экране нет. `cues.json` из черновика голоса не писался. `jobs/the-creator.json` не создавался: без реплик конвейер доходит до prove и падает. `timing.status` остаётся draft, у каждой строки флаг `timing-draft`, пословная заливка выключена.

Черновые окна в `lyrics.json` нужны только затем, чтобы скорость русского считалась по длине фразы, а не по всей песне. Это не выравнивание. В каноне в столбце «с» стоит «?».

Один открытый источник букв: https://awakeningrecordsmusic.bandcamp.com/track/the-creator . Огласованного арабского издания нет, строки ar оставлены латиницей страницы. Обратный перевод не делался: в review фраза «обратный перевод: ждёт Gemini».
