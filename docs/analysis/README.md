# Анализ записей

Что конвейер в песочнице (Demucs → `sections.py` → Whisper large-v3-turbo) нашёл в каждой записи. Это карта, а не текст: по ней видно, где поёт голос, где играют инструменты, и что примерно звучит. Текст песни берётся из канонических источников ([стадия 4](../methodology/04-text.md)).

Вывод по трём песням Sami Yusuf (живые концертные записи, хор, мелизмы, смена языков):
- **Карта голоса** (`sections.suggested.json`: участки, где в вокальной дорожке есть голос, паузы > 3 с) надёжна — по ней строится структура.
- **Whisper** надёжен только на сольном английском и турецком. На хоре, арабском и персидском он пропускает целые куски (VAD отбрасывает протяжное пение), путает язык и пишет несуществующие слова («Altyazı M.K.», «İzlediğiniz için teşekkür ederim» — это галлюцинации субтитров из обучающих данных). Использовать только как подсказку порядка куплетов.
- Поэтому пословное время даёт **принудительное выравнивание** (MMS) канонического текста по вокальной дорожке, а не транскрипт.
