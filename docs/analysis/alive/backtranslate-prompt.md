Прочитай docs/analysis/translation/alive.md в этом репозитории. Это досье перевода песни Alive.

Для каждого блока сверь поле «Принято» с полем «Оригинал». Сделай обратный перевод принятой русской строки на язык оригинала и сравни его с оригиналом. Замечание пиши только там, где расходятся лицо, время, число, образ или пропущено слово, которое в оригинале есть. Совпадение не записывай.

Ответ — JSON по схеме. Поле issues: массив замечаний. У каждого замечания:
- ids — id строк из поля «Строки» этого блока;
- gloss — короткий подстрочник оригинала;
- back — обратный перевод принятой русской строки на язык оригинала;
- note — в чём расхождение;
- proposal — как можно сказать по-русски ближе к оригиналу, без новых образов.

Если расхождений нет, верни пустой массив issues. Не переписывай досье и не меняй файлы песни.
