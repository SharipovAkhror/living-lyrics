## Находки маршрута (LL · Site)

- **Шифрование держит весь маршрут.** `song-status` после стадии 2 печатает только `npm run audio:encrypt`. Решение оркестратора на этом проходе: напечатанную команду шифрования не выполнять и брать следующую стадию таблицы, которая не «да». Структура и видео из-за этого сделаны локально.
