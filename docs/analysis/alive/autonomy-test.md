## Что не подтверждено

- Кадры ролика владельца.
- Что именно поётся и сколько раз, включая английский и турецкий.
- Печатный текст Фурузанфара по буквам.
- Имена музыкантов со страницы, которая отдала капчу.
- Шифрование отложено оркестратором. `song-status` по-прежнему печатает `npm run audio:encrypt` первой командой. Эта строка пропускается, берётся следующая стадия таблицы, которая не «да».
- Какие полустишия звучат в окнах голоса. Стем границу даёт, слова нет.
- Длительность файла 686,34 с сходится с карточкой ролика 11:26. Qobuz 11:12 остаётся другой шкалой.

## Находки маршрута (LL · Site)

- **Шифрование держит весь маршрут.** `song-status` после стадии 2 печатает только `npm run audio:encrypt`. Структура, строки текста, видео (9б, запуск agy) и всё дальнейшее в самой программе ждут ключа, хотя зашифрованный файл им не нужен. Исправить после теста, не сейчас: шифрование — условие коммита записи, а не следующих стадий; `song-status` показывает его отдельной строкой и идёт дальше. Решение оркестратора на этом проходе: напечатанную команду шифрования не выполнять и брать следующую стадию таблицы, которая не «да». Структура из-за этого сделана локально.
- **Ключ записи — у владельца.** На Станции `.env.local` не было. Секрет в GitHub есть, но агенту он не виден. Владелец кладёт ключ один раз (`AUDIO_KEY=…` в `.env.local` основной папки), дальше маршрут его не просит.
- **Запись.** Одна попытка `yt-dlp` прошла (формат 140). Файл владельца не понадобился.
