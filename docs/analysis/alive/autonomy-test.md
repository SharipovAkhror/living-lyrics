## Что не подтверждено

- Кадры ролика владельца.
- Что именно поётся и сколько раз, включая английский и турецкий.
- Печатный текст Фурузанфара по буквам.
- Имена музыкантов со страницы, которая отдала капчу.
- Шифрование: без `AUDIO_KEY` открытый m4a в репозиторий не кладётся, и `song-status` дальше записи не идёт.
- Длительность файла 686,34 с сходится с карточкой ролика 11:26. Qobuz 11:12 остаётся другой шкалой.

## Находки маршрута (LL · Site)

- **Шифрование держит весь маршрут.** `song-status` после стадии 2 печатает только `npm run audio:encrypt`. Структура, строки текста, видео (9б, запуск agy) и всё дальнейшее ждут ключа, хотя зашифрованный файл им не нужен: видео и текст берутся из ролика и источников. Из-за этого Gemini в этом прогоне не запускался. Исправить после теста, не сейчас: шифрование — условие коммита записи, а не следующих стадий; `song-status` показывает его отдельной строкой и идёт дальше.
- **Ключ записи — у владельца.** На Станции `.env.local` не было. Секрет в GitHub есть, но агенту он не виден. Владелец кладёт ключ один раз (`AUDIO_KEY=…` в `.env.local` основной папки), дальше маршрут его не просит.
- **Запись.** Одна попытка `yt-dlp` прошла (формат 140). Файл владельца не понадобился.
