# Nasimi — журнал обходов

- В системе не было ffmpeg и ffprobe (`where.exe` пустой). Вместо установки в репозиторий взяты локальные бинарники в `%LOCALAPPDATA%\ffmpeg-bin`: ffmpeg из imageio-ffmpeg 7.1 и ffprobe 6.1 (сборка gyan.dev). Иначе `process_audio.py` не измеряет файл.
- У дорожки 140 в теге потока `bit_rate` стоит 2256, у контейнера 129481. Скрипт смотрит тег потока и пишет «2 kbit/s», копию saver не делает. Контейнер тоже ниже порога 160 кбит/с, поэтому отдельный saver по правилу стадии 2 не нужен. Файл не перекодировался.
- `song-status` после `separate.py` и `sections.py` снова печатает `separate.py`: строка «структура» остаётся «нет», пока в `lyrics.json` нет вокальных строк, а строки нельзя собрать без свидетеля. Повтор Demucs не запускался. Дальше взяты кадры титров и Whisper, как написано в стадии 4.
- `lyric_frames.py` сохранил 320 кадров: нижняя полоса кадра реагирует на смену плана, не на строку титра. Просмотрены кадры 0, 65, 176, 233, 340, 457, 511 и 556 с: концерт, оркестр, хор, солисты, титров со словами на экране нет. Все 320 кадров по буквам не читались. `agy` не вызывался, `captions.json` не записан: это файл Gemini, а не эта сессия.
- `transcribe.py` с `device=auto` искал `cublas64_12.dll` и падал, хотя `torch.cuda` недоступен. Повтор с `CUDA_VISIBLE_DEVICES=-1`: счётчик устройств CUDA стал 0, и тот же скрипт без правки кода считает на процессоре. Черновик — `work/nasimi/transcript.json`. Он редеет: середина пения выпала, часть фраз — типовые галлюцинации «Altyazı» и «İzlediğiniz için teşekkür ederim».
- Повтор без VAD и без замка языка за первые полторы минуты дал «Altyazı M.K.» и «Al-Fatiha» и был остановлен. Следующий проход — тот же large-v3, язык tr, VAD выключен, порог «не речь» снят, горячие слова только «sığmazam cahan Nasimi». Буквы в `lyrics.json` из этого прохода не копируются: в строки легли полустишия Викитеки, порядок — по этому черновику, время слов — равные доли окна фразы.
- `captions.json` не записан. Следующая команда `song-status` просит чтение титров через Gemini. Эта сессия Grok и `agy` не вызывает. Пустой массив captions не подставлен: он отметил бы все 320 кадров прочитанными. Выборка кадров уже в журнале выше.
- `vision.json` по той же причине не записан. Инструменты проигрышей остаются `ensemble` с флагом `attribution-unverified`.
- `song-status` после строк печатает чтение титров через Gemini и не доходит до задания выравнивания, пока нет `vision.json`. Выравнивание реплик и кадров не требует. Задание `jobs/nasimi.json` со стадиями separate, align, qa поставлено этим обходом: секунды слов в файле — равные доли окна, не замер.
- Проверка перевода через `codex_run.py`, модель gpt-6.1-sol, усилие high, не запустилась: пятичасовой предел 99 %, сброс 2026-11-01T19:00:42Z. Повтор один раз после сброса, до запроса на слияние. Обратный перевод до этого повтора не выдуман.
