# I Have Come Alive: инструменты по звуку

Предложение скрипта. В `lyrics.json` его переносит агент после сверки с титрами. Файл лежит рядом с картой голоса, а не в папке с тем же именем: `docs/analysis/i-have-come-alive.md` уже занят.

Модель: `laion/clap-htsat-unfused` (Apache-2.0). Стемы: htdemucs (MIT). Огибающие: librosa (ISC). Окно 2.5 с; шаг ударных 1.5 с, остальных стемов 2.0 с, смеси 3.0 с. Пороги общие для любой записи. Уверенность — средняя вероятность подсказки на окнах отрезка после сглаживания, не калиброванная доля истины. Сходство — косинус CLAP.

Длительность 580.06 с.
