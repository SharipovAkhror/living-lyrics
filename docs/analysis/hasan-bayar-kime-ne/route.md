# Kime Ne — ход маршрута

Официальное видео: канал Hasan Bayar, https://www.youtube.com/watch?v=DqcDknKODe4. Одна загрузка звука (дорожка 140) и одна загрузка видео (формат 18). Обе отдали файл. Субтитры запрошены один раз и оказались пусты.

Буквы — из описания ролика, один источник. Порядок исполнений — черновик распознавания вокала на CPU: штатный `transcribe.py` на этой машине выбирает CUDA и падает без `cublas64_12.dll`, код репозитория не менялся. Секунды этого черновика в таблицу эталона не переписывались. В `lyrics.json` они лежат только как черновые границы слов, у каждой строки флаг `timing-draft`, статус тайм-кодов `draft`.

Построчного текста на кадре нет. Файл реплик не составлен, задание выравнивания не запускалось.
