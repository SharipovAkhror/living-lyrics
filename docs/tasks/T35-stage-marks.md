# T35: голос и инструменты на сцене — сверка со звуком, аплодисменты без рисунка

Owner: LL · Site (выдаёт исполнителю, принимает). Report to `LL · Main` in short English. Исполнитель: Grok или agy (Antigravity, не Claude), задание — `docs/tasks/_executor.md` + этот файл.

Владелец (2026-10-22): «на сцене часто неверно: показывает голос, где его нет, и наоборот; иногда не те слова». Аплодисменты: распознать и ничего не рисовать — ни инструмента, ни голоса.

## Что есть
- Состав сцены — `content/songs/<slug>/lyrics.json` (секции, `instruments`, голоса), схема `src/data/schema.ts` (пустой список = пустая сцена, «applause and bows»), сборка — `scripts/instrument_id/` (`entries.py`: `APPLAUSE_LABEL`, `anchors.py`: `_CROWD`), лента — `src/data/timeline.ts`.
- Стемы Demucs и выравнивание — артефакты конвейера (`.github/workflows/pipeline.yml`, `docs/methodology/05-alignment.md`); видео-свидетель — Gemini (`agy`, читает файлы только внутри основной папки).

## Сделать
1. **Сверка по трём песням** (`i-have-come-alive`, `karitas`, `one`): для каждой секции/участка сцены — что рисуем (голос да/нет, какие инструменты) против звука: энергия вокального стема (порог из данных, не на глаз) + Gemini по видео как второй свидетель. Таблица расхождений `docs/analysis/stage-marks.md`: время, что рисуем, что слышно по стему, что видит Gemini, решение.
2. **Исправить** неверные метки в данных (не в коде под песню). Где свидетели расходятся — флаг и вопрос в `review`, не выдумывать.
3. **Аплодисменты:** детектор по звуку (широкополосный шум без высоты тона в стеме «other»/миксе, плюс видео-свидетель, если есть) → участок помечается как аплодисменты → сцена пустая (без инструмента, без голоса, без подписи «Аплодисменты» на сцене; в «Весь текст» можно оставить заметку). Встроить в стадию `9 инструменты` маршрута, чтобы новые песни получали это сами; `song-status` показывает число участков.
4. **Слова:** отдельной таблицей — строки, где владелец мог видеть «не те слова»: строки с флагом `timing-draft`, показанные с заливкой или в неверное время; убедиться, что недоказанные строки не заливаются (правило AGENTS.md).
5. Проверка в воротах: `npm run validate` ловит голос на участке, где вокальный стем ниже порога, и любой рисунок на участке аплодисментов.

## Готово, когда
- Таблица по трём песням, все расхождения закрыты или под флагом с вопросом; число исправлений по песням.
- Аплодисменты находятся автоматически и не рисуются; проверено кадрами сцены на этих участках (обе темы, телефон).
- `npm run validate && npm run typecheck`, `npm run test:layout` проходят; `song-status` трёх песен без новых красных стадий.
