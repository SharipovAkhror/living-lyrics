Владелец (2026-10-22, iPhone): во время прослушивания, ничего не трогая, сайт упал и начал с начала. По T27 после перезагрузки воспроизведение должно продолжаться с сохранённого места (общее с T28).

## Сделать
1. **Какая сборка была:** по Vercel (команда и проект — `docs/STATUS.md`) — какой production-деплой был живым 2026-10-21/22, есть ли в нём коммиты T27/T28 с возобновлением (`git merge-base --is-ancestor`). Записать хэши.
2. **Почему не сработало возобновление:** пройти путь сохранения позиции (что, куда, как часто пишется; что читается при загрузке; что при падении процесса WebContent, при выгрузке вкладки, при сбросе `sessionStorage`/`localStorage`, в приватном режиме, при смене версии сборки). Воспроизвести в WebKit (Playwright): убить страницу посреди песни (`page.close`/перезагрузка/`crash` где доступно) → открыть снова → позиция ±2 с, песня та же, пауза (iOS не даст автозапуск без жеста) с заметной кнопкой «продолжить с m:ss».
3. **Защита:** позиция пишется не реже раза в 2 с и на `pagehide`/`visibilitychange`; чтение терпит битые/старые данные; при ошибке рендера — граница ошибок, которая сохраняет позицию и восстанавливает сцену без перезагрузки; лог последней ошибки в `localStorage` (без личных данных), который показывается в «О песне» → для диагностики.
4. Если причина — снова память (T27), измерить и записать в `docs/performance/t27-iphone.md`.
