# Задача T1: синхронизация слов — до 90 % (цель 100 %) доказанных строк в каждой группе

Цель владельца: слова загораются ровно тогда, когда их поют. Пословная заливка включается для всей песни, только когда доказано **90 % строк в каждой группе** (соло, хор) — решение владельца 2026-10-20 (было 80 %, 2026-10-18); цель — 100 %, недоказанные строки тоже доводить. Доказательство не ослаблять: случайный проход строки ≤ 5 %, правила — `docs/methodology/05-alignment.md`.
