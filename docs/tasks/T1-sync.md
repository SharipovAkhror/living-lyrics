## Сделать

1. **Независимый свидетель, который слышит звуки, а не слова.** Фонемный выравниватель, не зависящий от MMS и Whisper: например, открытая wav2vec2/XLS-R модель, обученная на фонемах IPA (вроде `facebook/wav2vec2-xlsr-53-espeak-cv-ft` или новее), и фонемизация известного текста через espeak-ng (латынь, немецкий, азербайджанский, персидский и др.); или MMS-адаптеры языка, если они дают независимый от постановщика сигнал. Лицензии моделей записать (некоммерческие помечать, как MMS); веса в репозиторий не класть. Выбор — по замеру, не по догадке.
2. **Калибровка на тех же правилах.** Для нового свидетеля — случайный проход слова и строки на смещённых метках (как для Whisper); свидетель допускается к паре песня/язык, только если удерживает строку ≤ 5 %. Пороги не сдвигать ради процентов.
3. **Хор.** Проверить, чем хор отличается: атаки размыты, слова тянутся. Поискать честный признак для хора (атака по огибающей стема голосов, гласные-ядра, согласие нескольких свидетелей) с той же проверкой случайного прохода. Если честного способа нет — так и написать, с числами.
4. **Прогон в GitHub Actions** (`.github/workflows/pipeline.yml`, задание `jobs/<slug>.json`) для трёх песен; таблица «было/стало» по группам и языкам; отчёт `docs/analysis/<slug>-qa.md` обновить.
5. Если группа песни дошла до 90 % во всех группах — `timing.status` и флаги ставит конвейер по правилам, сайт включит заливку сам; руками время не двигать.
