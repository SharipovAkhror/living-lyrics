# Задача T22: иконки на выбор владельца и обложки без текста

Слова владельца (2026-10-19), после «мягкого стекла» (T21): «Мне не нравятся иконки — какие-то не мягкие и ИИ-слопные». И: «Обложки тоже не нравятся — попробуй без текста сделать».

Phosphor Regular, который сейчас на сайте (`src/ui/icons.tsx`), — тонкий контурный набор, который стоит в огромном числе сгенерированных интерфейсов: отсюда ощущение шаблона. Владелец выбирает глазами, поэтому сначала **лист сравнения**, потом внедрение выбранного (отдельным шагом после его ответа).

Зона: `src/ui/icons.tsx` (только после выбора), новая страница сравнения `/lab/icons` (`src/pages/lab/**`, регистрация маршрута — минимально), `scripts/art/covers.mjs`, `public/covers/**`, подпись плиток библиотеки (`src/pages/LibraryPage.tsx` и её стили), `docs/design/design-system.md` (раздел «Иконки», «Обложки»), `docs/instruments/credits.md` или новый `docs/design/credits.md` (лицензии наборов). Исходники наборов — скачать в `work/` (не в git), в сайт — только скопированные SVG-пути нужных значков с пометкой лицензии; новых зависимостей в `package.json` не добавлять.

## 1. Лист сравнения иконок

Нужные значки (как сейчас): назад, вперёд-шеврон, вниз, закрыть, пуск, пауза, предыдущая и следующая строка, перевод, пояснение, весь текст, настройки, сетка, книга/методология, поиск, сведения (i), флажок «Не совпадает», звук, скачать.

Варианты (все — с открытой лицензией, без SF Symbols):
- **A. Phosphor Fill** — те же формы, но залитые (мягче, плотнее).
- **B. Fluent UI System Icons, Filled** (Microsoft, MIT) — мягкие скруглённые залитые формы.
- **C. Material Symbols Rounded, Fill 1** (Google, Apache 2.0) — округлые залитые.
- **D. Свой набор**: 18 значков точной геометрией — толстая линия (≈ 2 px на 24) с полными скруглениями концов и углов, крупные радиусы, оптические поправки (круг чуть больше квадрата), единая сетка 24; без «модных» деталей. Это должно выглядеть рукой дизайнера, а не генератором.
- **E. Без иконок** во вкладках плеера: только слова на мягких стеклянных пилюлях (иконки остаются лишь у пуска/паузы/назад/вперёд/закрыть).

Страница `/lab/icons`: для каждого варианта — настоящая капсула плеера (время, флажок, полоса, назад/пуск/вперёд, вкладки) и шапка песни, тёмная и светлая тема, iPhone 393×852. Кадры: `work/shots/t22/icons-<A…E>-{dark,light}.png` и одна сводная картинка `work/shots/t22/icons-all.png` (все варианты рядом, подписаны буквами). Сайт пока не меняй.

## 2. Обложки без текста — сразу

`scripts/art/covers.mjs`: обложка = только мягкое поле цвета песни (палитра `palette.field` из `song.json`, как живой фон песни, застывший в красивом кадре: 3–4 размытых цветовых пятна, лёгкое свечение, тонкое зерно против полос), без букв и знаков. Каждая песня узнаётся по цвету. Размеры прежние (96, 192, 512, 1024), квадрат во весь кадр. `coverGlyph` больше не рисуется (поле в схеме оставить, пометить как неиспользуемое).
Плитка библиотеки: на стекле — название песни (крупно) и подзаголовок/исполнитель (мельче). Кадры: `work/shots/t22/covers.png` (три обложки 512 рядом) и библиотека iPhone тёмная/светлая.

Проверки: `npm run validate && npm run typecheck`, `npm run test:layout`, `npx vite build`. Коммиты: обложки отдельно, лист сравнения отдельно. Отчёт коротко: пути к `icons-all.png` и `covers.png`.

Готово, когда: обложки без текста в сайте; лист сравнения пяти вариантов иконок снят; владелец выбирает — внедрение выбранного варианта будет следующим шагом.

### 1. Иконки: вариант A (Phosphor Fill) — во весь сайт, чётко

- `src/ui/icons.tsx`: все значки — Phosphor **Fill** (пути из того же коммита, что в `src/pages/lab/iconSets.ts`, вариант A), пометка лицензии MIT и источник в шапке файла.
- **Чёткость**: значки рисуются в целых размерах, кратных сетке (16 / 20 / 24 / 28 px; во вкладках плеера 24, в шапке 22–24, на пуске 28–32), без дробного масштаба и без `transform: scale` на самом значке (сжатие при нажатии — на кнопке-контейнере), `shape-rendering: geometricPrecision`, координаты контейнеров целые — на iPhone (3×) и на десктопе (1×) края не мылятся. Одинаковый оптический вес: круглые значки на 1 px крупнее квадратных, если иначе выглядят мельче.
- Активная вкладка — цвет акцента, неактивные — приглушённые, но читаются (контраст ≥ 3:1 к стеклу).
- Страницу `/lab/icons`, `src/pages/lab/iconSets.ts`, `icons-lab.css` и её маршрут — удалить (выбор сделан; лицензии оставить в `docs/design/credits.md` только для Phosphor). Устаревшее, что ты отметил в отчёте: `src/components/Cover.tsx` (если нигде не используется — удалить), описание обложки в `scripts/tools/song-status.ts`.

### 2. Обложки: официальные

- Источник — официальная обложка релиза каждой песни (сингл или альбом Sami Yusuf), без ключей и регистрации: iTunes Search API (`https://itunes.apple.com/search?term=...&entity=song` → `artworkUrl100`, заменить размер на `1000x1000bb`) или официальный трек/альбом в Apple Music. Сверь, что это именно тот релиз, что в `song.json`/`sources.md` (название, год, версия). Если релиза нет (живая версия без отдельной обложки) — кадр-превью официального видео из `sources.md` (`https://i.ytimg.com/vi/<id>/maxresdefault.jpg`), обрезанный в квадрат по центру. Что взято и откуда (URL, дата) — в `sources.md` каждой песни.
- Файлы: `public/covers/<slug>/{96,192,512,1024}.jpg` (качество 85–90, без скруглений), исходник 1000–1024 — один раз скачан, остальные размеры — уменьшением (Python Pillow или уже установленный Playwright; новых npm-зависимостей не добавлять). Генератор полей (`scripts/art/covers.mjs`) остаётся запасным для песни без официальной обложки: `npm run art -- covers` сначала ищет официальный файл, иначе рисует поле. В `song.json` — поле источника обложки, если схема позволяет (обнови схему и `docs/data-format.md`).
- Media Session и плитки библиотеки — официальные обложки; на плитке подпись на стекле как сейчас (название и исполнитель).
- Права: обложки — собственность правообладателей; владелец решил использовать их (сайт некоммерческий, закрыт паролем). Запиши это решением в отчёт; в `docs/design/credits.md` — строка «обложки — официальные, © правообладатели, источник в sources.md».
