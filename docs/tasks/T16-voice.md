# Задача T16: новые гравюры «голос» и «хор» — живые люди

Слова владельца (2026-10-18): «Иконку голоса поменяй: убери оттуда человека без лица, и человека сделай». Сейчас `voice` — бюст в профиль без черт лица; `choir` — раскрытая книга на пюпитре.

Зона: `scripts/art/instruments/voice.mjs`, `scripts/art/instruments/choir.mjs`, `src/instruments/svg/voice.svg`, `src/instruments/svg/choir.svg`, `src/instruments/art.json`, описание в `src/instruments/list.ts`/каталоге (если меняются подписи), `docs/methodology/09-instruments.md` (стиль), `docs/instruments/**`.

Сделать:

1. **Голос** — поющий человек с лицом: черты лица читаются (глаза, брови, нос, губы, приоткрытый поющий рот), спокойная поза певца суфийской и классической традиции (например, в три четверти, рука у груди или ладонь раскрыта), одежда без карикатуры, без узнаваемого конкретного человека. Стиль каталога: линия, штриховка, только `currentColor`, медальон. Анимация по контракту: `.breath` (дыхание) и лёгкое движение рта/груди как функция времени; без «моргающих» эффектов.
2. **Хор** — группа поющих людей (3–5 фигур в два ряда, лица с чертами, рты открыты, у кого-то папки с нотами), а не книга. Тот же стиль и `.breath`.
3. Обе гравюры читаются и на телефоне крупно, и мелко на десктопе среди других инструментов; не спорят с инструментами по яркости. Пропорции людей правильные (не «кукольные»).
4. Проверка: `npm run art -- voice` и `choir`, `npm run validate && npm run typecheck`, `npx vite build`; кадры в `work/shots/t16/`: галерея (светлая и тёмная), сцена Karitas начало (хор, `?t=8`) и I Have Come Alive `voice-open` (`?t=12`) на iPhone и десктопе, тёмная. Что видно — в отчёте.
