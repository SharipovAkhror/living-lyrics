# Добавление песни

Вход: `$ARGUMENTS` — ссылка на запись или путь к аудиофайлу. Больше ничего не дано: текст, перевод, тайм-коды, имена музыкантов вы находите сами.

Полный регламент — `docs/methodology/` (стадии 01–12). Здесь — порядок действий и проверки. Читайте файл стадии перед тем, как её делать.

## 0. Подготовка
- Убедитесь, что есть `ffmpeg`, Python 3.10+, `npm install` выполнен.
- Создайте ветку `song/<slug>` после того, как определите slug.
- Заведите список задач по стадиям ниже и отмечайте выполнение.

## 1. Опознание — `docs/methodology/01-intake.md`
- Точно определить запись (студия / live — где и когда, длительность).
- Найти официальное описание: авторы текстов, языки, солисты, лады.
- `npm run new-song -- <slug> "<Title>" "<Artist>"`, заполнить `song.json`, `sources.md`.

## 2. Аудио — `02-audio.md`
- `scripts/pipeline/fetch_audio.sh <slug> "<url или путь>"`
- `python3 scripts/pipeline/process_audio.py <slug>`
- Проверить: `audio.status = ready`, `duration` совпадает с файлом.

## 3. Структура — `03-structure.md`
- `python3 scripts/pipeline/separate.py <slug>` → `python3 scripts/pipeline/sections.py <slug>`
- Если есть видео: `python3 scripts/pipeline/frames.py <slug>` и посмотреть кадры, чтобы узнать инструменты.
- Секции `vocal` / `instrumental`, ключи инструментов из `src/instruments/list.ts`. Имена исполнителей — только подтверждённые.

## 4. Текст — `04-text.md`
- `python3 scripts/pipeline/transcribe.py <slug>` — черновик.
- Найти канонический текст (Ganjoor, издания диванов, Cantus…), сверить с записью, записать то, что поётся, с повторами.
- Орфография по языку; разбивка на строки (`|` — перенос, `^` — ключевое слово).

## 5. Тайм-коды — `05-alignment.md`
- `python3 scripts/pipeline/align.py <slug>`; просмотреть отчёт.
- Проблемные места — по отчёту `qa_sync.py` (стадия 5/11): исправить текст или порядок строк и выровнять снова; руками время не двигать.

## 6–8. Перевод, пояснение, транскрипция — `06-translation.md`, `07-comment.md`, `08-transliteration.md`
- Перевод строка к строке, ≤ 17 зн/с, без пафоса.
- Пояснение только с источниками; сомнения — словами «требует проверки».
- Кириллическая транскрипция для всех строк арабским письмом.

## 9. Инструменты — `09-instruments.md`
- Ключи в `instruments` — ведущий первым, только то, что слышно; исполнители — «Имя (инструмент)».
- Раскладку гравюр сцена выбирает сама; `layout` — только если выбор спорит со смыслом (солист и аккомпанемент → `hero-insets`).
- Нет инструмента в каталоге — добавить в `list.ts`, нарисовать генератор в `scripts/art/instruments/`, `npm run art -- <key>`, проверить PNG.

## 10. Хореография — `10-choreography.md`
- Обычно ничего не нужно: сцена — поток строк. `^` — одно ключевое слово, `|` — перенос на цезуре.

## 11. Проверка — `11-qa.md`
- `npm run validate -- <slug>` — 0 ошибок; `npm run typecheck`.
- `npm run dev` и `npm run shots -- http://localhost:5173 work/shots "/song/<slug>?t=<сек>"` в 3–4 точках песни; посмотреть скриншоты.

## 12. Публикация — `12-publish.md`
- Коммит в ветку `song/<slug>`, push. `work/` не коммитить.

## Отчёт пользователю
Коротко: что за запись и откуда файл; сколько строк и языков; статус тайм-кодов (`aligned`/`verified`); что осталось в `review` и почему (например, «имя кануниста не найдено в источниках»). Не называйте песню готовой, если `review` не пуст.
