# Восстановление после выключения Станции

Правило владельца — `docs/process/after-restart.md`. Ты временный чат. Подними пять рабочих чатов (по одной записи на каждый), отчитайся LL · Main и уйди в архив. С владельцем говори по-русски и коротко.

1. **Вход.** Запусти `python ops/agents/recover.py --dry-run`. Код выхода 2 значит, что в терминале нет входа. Дай владельцу одну команду в блоке `bash` (у блока в приложении есть кнопка Run): `claude auth login`. Попроси нажать в браузере Authorize и написать «готово». Сам не входи и пароли не вводи. Пока ждёшь, сделай шаг 2.
2. **Копии в приложении.** Возьми `list_sessions` (инструменты приложения) и `claude agents --json --all`. Если запись приложения не в архиве, её имя совпадает с именем рабочего чата (`.claude/agents/ll-*.md`, поле `chat`) и номер (`local_<id>`) совпадает с номером фонового чата этого имени, это тот же разговор: `archive_session`. Если номер другой, запись не трогай и назови её в отчёте. Перечёркнутые записи Remote Control в `list_sessions` не входят: после шага 3 они оживают сами.
3. **Подъём.** Запусти `python ops/agents/recover.py`. Он перезапускает каждый чат без процесса (`claude respawn`, тот же разговор) и печатает по строке на чат.
4. **Resume.** Если чат печатается как `waits: dialog open`, ответить на этот вопрос может только владелец: открыть этот чат и выбрать Resume. Назови ему эти чаты списком. Если он отошёл, пошли push.
5. **Проверка.** `python ops/agents/registry.py`: у всех пяти чатов есть процесс. Записи приложения из шага 2 в архиве.
6. **Отчёт.** LL · Main — `SendMessage`, коротко по-английски: что поднято и что ждёт владельца. Владельцу — одна строка: «Чаты подняты, пишите в LL · Main».
7. **Архив.** Спроси владельца кнопкой (AskUserQuestion), можно ли закрыть этот чат. После «да» — `archive_session` с `self`.

Не делай: не открывай перечёркнутые чаты и не пиши в них; не запускай `claude --resume` с флагами; не создавай новых рабочих чатов. Новый рабочий чат появляется только через `rotate_chat.py`.
